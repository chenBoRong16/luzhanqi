# 擴充版大翻新：規格（SDD 第 1 步）

狀態：2026-10-03 重寫；實作中依統計補上 2.9「兵力」（使用者選 C：坦克撞雷就死，另外補排雷手段）。

## 0. 依據

**需求**：
- 重新設計安全區類地形：現在行營比碉堡安全，名不副實。
- 規則大翻新、地圖重製。
- 同一輪討論到的：坦克撞地雷、大本營、傘兵。

**`我個人/功能.md` 的規則要求**：
> 在不破壞遊戲性的前提下，規則有一定現實合理性 且 無太多突兀的例外性規則(正例:通用性規則)，以方便理解。（軟性條件、加分項）

**不變的條件**：
- **原版不動**，照傳統規則。
- 須兼容做成棋盤遊戲：只看格子和棋種，不做數值計算。
- 擴充版-0 不能有等效等級規則。
- 遊戲性優先於合理性。

## 1. 設計原則

1. **通用性規則優先**：一條規則對所有棋、所有同類格子都成立，不針對個別棋或格子另寫特例。
2. **六個概念**：每條規則只屬於一個概念，規則文件裡也只寫一次。
   - **移動**：一手能走到哪裡。
   - **攻擊**：撞上之後誰留下。
   - **視線**：什麼看得到。
   - **防護**：什麼打不到。
   - **翻倒**：什麼時候暫停一回合。
   - **開局**：哪裡能放什麼。
3. **地形只說「屬於哪幾個概念」**，例如森林＝隱蔽＋翻倒；細節回到概念去看。
4. 每條規則寫清楚**條件和後果**。說得出一句理由的例外才留（見第 6 節）。

## 2. 擴充版規則（定案）

### 2.1 移動

- **公路**：走 1 格；行營和四周八格有斜線。
- **鐵路**：
  - 沿同一條鐵路直線走，格數不限。
  - 遇到第一顆棋就停：是敵棋可以攻擊它，是自己的棋就停在它前面。
  - 工兵可以在鐵路的交叉口轉彎。
- **軌距**：
  - 標準軌、寬軌：照上面的鐵路規則。
  - **窄軌**：一手最多走 3 格；任何棋都可以順著窄軌轉彎；坦克不能走窄軌。
  - **換軌站**（兩種軌距相接的格子）：沿鐵路走到這裡就停，工兵也一樣。
- **坦克衝刺**：
  - 沿公路連走 2 格，可以轉一次彎；**整段都在平原上時最多 3 格**。
  - 經過的格子要空，而且不能是沼澤、森林；最後一格可以是敵棋（攻擊）。
  - 不衝刺時照一般棋走 1 格。
- **空降**：
  - 每顆傘兵一盤一次，用一手從任何位置跳到對方前 3 列的空格。
  - 落點只能是一般格或平原，而且不在對方防空炮旁。
  - 空降時不能攻擊；落地後翻成明棋，並且翻倒。
- **村莊出發**：從村莊出發的棋，這一手只能沿公路走 1 格（不能走鐵路、衝刺、空降）。
- **大本營**：
  - 任何棋都可以走出大本營。軍旗、地雷本來就不能動。
  - 走進**對方**大本營的棋翻成明棋。
- **通行**：高山不能進入；坦克不能進入沼澤。

### 2.2 攻擊

- **等級**（11 級，由大到小）：司令 ＞ 軍長＝坦克 ＞ 師長 ＞ 旅長 ＞ 團長 ＞ 營長 ＞ 連長＝防空炮 ＞ 排長＝傘兵＝狙擊手 ＞ 工兵＝偵察 ＞ 間諜 ＞ 雷達站。
- **沒有等級的棋**：炸彈、地雷、軍旗。
- **結果**（依序判斷）：
  1. 被攻擊的是軍旗：攻擊方贏得這盤。
  2. 任一方是炸彈：雙方都移除。
  3. 被攻擊的是地雷：工兵攻擊時地雷移除，工兵移過去；其他棋（含坦克）攻擊時，攻擊方移除，地雷留著。
  4. 間諜主動攻擊司令：間諜贏。
  5. 其餘比等級：大的贏並移過去；小的移除；同級雙方都移除。
- 原本的特例都改成照等級比：
  - 防空炮被傘兵攻擊必勝、雷達站被攻擊就移除：結果不變，交給等級比較。
  - 坦克破雷：刪除，坦克撞地雷照一般棋。

### 2.3 視線

- **看得到**：沿公路數到目標的步數在距離以內，不管路上有沒有棋，而且目標不在**隱蔽**格（森林、村莊）。
- **暴露**：目標站在**平原**上時，距離多 1。
- **偵察**：
  - 用一手偵察一顆看得到的敵棋，距離 2。
  - 已經確定是什麼的棋不能再偵察。
  - 偵察後，被偵察的棋和偵察自己都翻成明棋。
- **雷達站**：每一手結束時，看得到的敵棋都翻成明棋，距離 1。
- **狙擊**（擴充版-1）：
  - 目標是沿公路直走第 2 格的敵棋，第 1 格要空；目標不能在隱蔽格或防護格裡。
  - 目標比營長小就移除；否則失敗，目標不動。沒有等級的棋狙擊不了。
  - 狙擊手不論成敗都翻成明棋。

### 2.4 防護

- **防護格**：行營、碉堡。裡面的棋**不能被攻擊**，炸彈、坦克、狙擊都一樣。
- **爆破**：
  - 對方的**工兵**用一手爆破防護格。
  - 位置：工兵要攻擊得到那一格，也就是公路相鄰（含行營斜線），或沿鐵路走得到。
  - 只能爆破對方半場的防護格；空的也可以。
  - 結果：
    - 這格永久失去防護，變成一般格，公路照舊。
    - 工兵留在原地，翻成明棋。
    - 裡面的棋不動。
- **行營和碉堡的差別**：

| | 行營 | 碉堡 |
|---|---|---|
| 開局 | 必須空著 | 可以放棋 |
| 公路 | 和四周八格相連，可以斜走 | 一般格的公路 |
| 位置 | 沿進攻路線，當中繼站 | 要道，例如公路橋的橋頭 |

- **兩個擴充版都有碉堡**。原本的「碉堡加一級」刪除。
- 碉堡格照樣可以炸橋；橋斷了，碉堡還在。

### 2.5 翻倒

- 走到森林、走到沼澤、傘兵空降落地時翻倒。
- 翻倒的棋在它主人的下一回合不能做任何動作；那一回合結束時扶正。
- 翻倒的棋照樣可以被攻擊，等級不變。
- 一方的棋全部翻倒而無棋可走時，跳過這一回合，不算輸。

### 2.6 開局

- **不能放棋的格子**：行營、沼澤、高山。
- 照傳統：
  - 軍旗放在大本營。
  - 地雷只能放最後兩列。
  - 炸彈、雷達站不能放第 1 列。

### 2.7 其他（照舊）

- **勝負**：奪下軍旗就贏；輪到自己時無棋可走就輸。
- **判和**：連續 N 手沒有棋被吃掉就和棋；攻擊或狙擊命中時歸零。N 可以在「設置」改或關掉。
- **炸橋**：炸彈站在任一方的橋頭時，可以用一手炸橋；炸彈移除，這一欄從此不能過河。
- **司令陣亡**：自己的軍旗翻成明棋。

### 2.8 兵力（實作中依統計決定）

- **工兵 4 → 6 顆，連長、排長各 2 → 1 顆**；總兵力不變（擴充版-0 35 顆、擴充版-1 36 顆）。
- 理由：坦克撞地雷就死之後，只剩工兵能排雷，雷區很難打開，和棋變多、對局拖長。工兵多兩顆，才打得開雷區。
- 統計（80 盤，舊地圖）：
  - 擴充版-0：先手 50%、和棋 8%、平均 132 手。
  - 擴充版-1：先手 45%、和棋 9%、平均 142 手。
  - 比較：工兵 4 顆時，擴充版-0 和棋 17%、184 手。
- 測過但不採用的做法：
  - 坦克撞雷雙方移除：和棋 20%。
  - 炸彈排雷：和棋 19%，而且要多一條例外。
  - 工兵直接多 2 顆、總兵力加 2：先手 38%。
  - 2 顆排長都換成工兵：擴充版-1 和棋 13%，但排長會完全消失。

### 2.9 擴充版-1

擴充版-0 的全部規則，加上狙擊手（2.3）。

## 3. 規則開關

- 分成**新棋**、**地形**、**機制**三組。
- **刪除**：「坦克破雷」。
- **新增**（機制組，預設開；關掉時恢復傳統）：
  - 「防護格可以被爆破」：關掉時防護格完全打不到。
  - 「棋可以走出大本營」：關掉時進了大本營不能再動。
- 「碉堡」移到擴充版-0 就有。

## 4. 地圖重製

### 4.1 原則

- **手工設計**：每一格都是刻意放的，不用隨機筆刷。
- 每張地圖**一個主題**、一個主要的取捨。
- **至少三條進攻路線**，地形各不相同。
- **安全區的位置有意義**：碉堡守要道，行營當中繼站。
- **雙方鏡像對稱**（兩國換軌除外，並標明不對稱）。
- **印得出來**：黑白列印分得清。

### 4.2 範圍

| 地圖 | 處理 |
|---|---|
| **標準**（擴充版預設） | **大翻新**：大小 7 × 7 和過河口（三鐵路、兩公路橋、兩座山）不變，三條路線各有特色，草案見 4.3 |
| 兩國換軌 | 主題不變；配合碉堡、行營重排；統計已達標，盡量少改 |
| 偏遠平原 | 重畫：連續的平原走廊給坦克衝，村莊在後方 |
| 沼澤森林 | 重畫：一翼沼澤、一翼森林，中路暢通 |
| 山地 | 重畫：高山形成山口，窄軌穿過山口，但不打開中路 |
| 新地圖 | 不新增 |

### 4.3 標準地圖草案（每方，第 1 列是前線）

```
       1     2     3     4     5     6     7
第1列  ═══  [堡]  ═══   ═══   ═══  [堡]  ═══    前線鐵路；[堡]＝橋頭碉堡
第2列  ║    (營)  {林}   ║    <原>  (營)  ║
第3列  ║    {林}  (營)   ║    (營)  <原>  ║
第4列  ║    (營)  {林}   ║    <原>  (營)  ║
第5列  ║     ·    (營)   ║    (營)   村   ║
第6列  ═══  ═══   ═══   ═══   ═══  ═══   ═══    後方鐵路
第7列   ·    ·    [本]   ·    [本]   ·    ·
```

- **左路**是森林帶：好藏身，但走進去會翻倒。
- **右路**是平原帶：坦克能衝，但容易被看到。
- **中路**是鐵路：最快，但完全暴露。
- 確切的格子在實作時依統計調整。

### 4.4 驗證

- 每張地圖兩版各 60 盤，最難對最難。
- 目標：
  - 先手 40～60%。
  - 和棋 ≤ 15%。
  - 主題地形每盤至少用到 0.3 次。
- 不達標就調整，最多 3 輪；還不行就回報數據和選項。

### 4.5 相容

- 舊佈局檔、棋譜照樣能讀：棋譜裡存了整張地圖。
- 使用者自己存的地圖不受影響。
- 地圖編輯器的空白範本不變。
- 預設、最強、惡搞最差佈局**重新產生**。

## 6. 例外與理由

保留下來的例外，每條都說得出一句理由。這張表會放進規則文件的附錄。

| 例外 | 理由 |
|---|---|
| 炸彈撞誰都同歸於盡 | 一爆連自己一起炸掉 |
| 只有工兵能排雷 | 地雷是一片雷區，要專業工兵才清得掉 |
| 間諜主動攻擊司令時贏 | 刺客專殺指揮官 |
| 司令陣亡，軍旗翻成明棋 | 指揮崩潰，司令部的位置跟著暴露 |
| 工兵能在鐵路上轉彎 | 工兵就是鐵道兵，熟悉路網 |
| 窄軌上任何棋都能順著軌道轉彎 | 火車順著軌道走，窄軌彎道多 |
| 坦克衝刺；不能進沼澤、不能走窄軌 | 裝甲跑得快，但太重 |
| 換軌站要停 | 軌距不同，車廂過不去 |
| 防護格只有工兵能爆破 | 工事擋得住衝鋒，要靠工兵爆破 |
| 森林、沼澤會翻倒 | 難走，要停下來重整 |
| 森林、村莊看不到；平原容易被看到 | 有沒有遮蔽 |
| 從村莊出發只能沿公路走 1 格 | 巷弄狹窄，出不快 |
| 偵察時自己也曝光 | 偵察兵靠近了，對方也看見他 |
| 防空炮旁不能空降 | 會被打下來 |
| 傘兵只能跳到對方前 3 列 | 空降部隊要在己方火力支援範圍內；遊戲上也避免直接空降到大本營旁 |
| 走進對方大本營翻成明棋 | 攻進指揮部，行蹤一定曝光 |
| 地雷只放最後兩列、炸彈不放第 1 列 | 傳統規則 |

## 7. 衝突與決定

| # | 衝突 | 決定 |
|---|---|---|
| F1 | 防護格打不動 → 可能僵局、和棋變多 | 工兵能爆破，炸彈能炸橋；統計和棋明顯變多時先回報，再考慮讓炸彈也能爆破 |
| F2 | 等級表簡化 → 同級相撞雙方移除的情況變多 | 看統計；先手勝率、和棋率偏離時回報。實測影響不大 |
| F6 | 坦克撞雷就死 → 雷區打不開，和棋 17～20%、對局長一倍 | 已回報；使用者選「另外補排雷手段」，依統計採用 2.8「工兵 6 顆」 |
| F7 | AI 把工兵浪費在爆破空的行營（每盤約 3 次） | AI 只在防護格裡有棋時才爆破 |
| F3 | 碉堡移到擴充版-0 → 擴充版-0 的標準地圖改變 | 重新產生預設、最強、惡搞最差佈局 |
| F4 | 刪除「坦克破雷」等規則 → 舊棋譜 | 舊棋譜照它當時的規則重播，結果不變 |
| F5 | 誘餌大本營的棋可以動了 | 它一動就洩漏「這邊沒有軍旗」，所以實際上仍會留著；這是玩家的選擇 |

## 8. 驗收

- **測試**：第 2 節每條新規則至少 1 項；舊棋譜重播結果不變。
- **回歸**：
  - 原版逐手一致。
  - 擴充版重錄基準，舊基準留存。
- **AI**：
  - 會用爆破，會走出大本營。
  - 不把防護格裡的棋當攻擊目標。
  - 「最難」贏「簡單」；深度 2 贏深度 1。
- **地圖**：照 4.4。另外，爆破、走出大本營在所有地圖合計每盤都有用到。
- **佈局**：
  - 新的預設、最強、惡搞最差佈局合法、可匯入。
  - 最強確實比預設強，最差確實比隨機弱。
- **文件**：
  - 規則文件照六個概念重寫，每條規則只出現一次。
  - 附錄「例外與理由」。
  - 遊戲內說明、規則開關、地形圖例同步。
  - 配件清單加「已炸毀」標記。
