## 2. P1 規則

### 2.1 `shared/expanded-base.js`：棋種與開關

- **等級**：
  - 坦克 9（＝軍長）
  - 防空炮 4（＝連長）
  - 傘兵 3（＝排長，和狙擊手相同）
  - 偵察 1（＝工兵）
  - 間諜維持 0.5
  - 雷達站改成 0.2（最小）
- **規則開關**：
  - 每項加 `group`：新棋、地形、機制。
  - 刪除「坦克破雷」。
  - 「碉堡」改成 `level: 0`，說明改成防護格。
  - 新增「防護格可以被爆破」（`blast`）、「棋可以走出大本營」（`hqExit`），都放在機制組。

### 2.2 `shared/engine.js`

| 規格 | 改動 |
|---|---|
| 2.2 攻擊 | `resolveAt` 刪掉三條特例：防空炮必勝、雷達站必輸、坦克破雷。刪掉 `rankUp`、`defRank`（碉堡加一級） |
| 2.3 狙擊 | `snipeHits`：目標沒有等級就失敗，否則比營長。目標格是防護格時不能選 |
| 2.4 防護 | `movesFor` 的 `consider`：目標格是沒被炸毀的防護格（行營、碉堡）時，任何棋都不能攻擊 |
| 2.4 爆破 | 新動作 `blast`：工兵能攻擊得到的格子，如果是對方半場、沒被炸毀的防護格，就多一個「爆破」選項，空格也算。`applyMove`：記進 `S.ruined`、工兵翻成明棋、判和計數加 1 |
| 被炸毀的格子 | `S.ruined` 照 `S.broken`（斷橋）的做法：存進悔棋點、棋譜重播時重現、AI 的模擬盤面也複製；被炸毀的格子不再算防護格，公路照舊 |
| 2.1 大本營 | 刪掉「大本營裡的棋不能動」（開關關掉時保留）；走進對方大本營時翻成明棋（`enter`） |
| 2.1 空降 | 落點只能是一般格或平原，而且不在對方防空炮旁 |
| 2.6 開局 | `placementError` 改成一條：行營、沼澤、高山開局不能放棋 |
| 2.1 移動其餘、2.3 視線其餘、2.5 翻倒 | 已經是規格寫的樣子，引擎不用改 |

### 2.3 舊檔案相容

- **舊棋譜**：新棋譜帶一個隱藏規則鍵 `v3: true`。
  - 沒有這個鍵的舊棋譜，整組改用舊規則：舊等級、三條特例、碉堡加一級、舊的空降與開局限制、大本營不能動、防護格不能爆破。
  - 引擎裡新舊兩套並存，只看這一個鍵切換，舊棋譜重播結果不變。
- **舊佈局檔**：比對規則時只比會改變兵力的開關（新兵力、防空炮、雷達站、狙擊手），其他不同也不跳出「要不要切換規則」。
  - 在有沼澤的地圖上，舊佈局可能因新的開局規則而不合法，照現有流程提示即可。
- **瀏覽器裡存的開關**：沒有的新開關照預設開。

### 2.4 測試（`tests/test.js`）

- **改寫**：
  - 碉堡加一級、坦克破雷、等級比較。
  - 狙擊、防空炮、雷達站。
  - 沼澤開局、空降落點、大本營。
- **新增**：
  - **防護格**：
    - 任何棋都打不了（含炸彈、坦克、狙擊）。
    - 爆破：只有工兵、只能爆破對方半場、空的也行；工兵翻明；判和計數加 1；之後照一般規則；行營斜線照舊。
    - 開關關掉時打不到、也不能爆破。
  - **碉堡**：可以開局放棋；碉堡格照樣炸橋。
  - **大本營**：任何棋都能走出；走進對方大本營翻明；開關關掉照傳統。
  - **等級**：同級雙方移除，例如坦克撞軍長、傘兵撞排長。
  - **舊棋譜**：用備份版產生一份舊棋譜，用新版重播，結果相同。

## 3. P2 AI（`shared/ai.js`、`ai-search.js`）

- AI 的走法、威脅範圍都來自 `movesFor`，所以防護格、大本營、空降、開局的新規則會自動跟上。
- **只新加爆破的評分**：
  - 加分：防護格裡可能的棋越大、這格擋住的路越重要，分數越高。
  - 扣分：工兵翻明之後被吃的危險。
- 刪掉坦克破雷相關的加分。
- 推演用的模擬盤面複製 `S.ruined`。

## 4. P3 地圖（`shared/maps-builtin.js`、`shared/map.js`）

- `maps-builtin.js` 改成**手工格子圖**：每列一行字串，加上鐵路、過河口清單，雙方鏡像。
- **新的標準地圖**取代擴充版的預設地圖（`mapFromConfig`），草案見規格 4.3。
- `baseMap`（編輯器的空白範本）不變。
- `map.js`：
  - 碉堡在擴充版-0 也能用，刪掉「碉堡只有擴充版-1」的檢查。
  - 加上「已炸毀」防護格的畫法。
- 刪掉 `tests/map-geometry-check.js`：它比對的是舊標準地圖和舊建法，標準地圖換掉後就沒有意義。
- **流程**：
  1. 每張地圖兩版各跑 60 盤。
  2. 不達標就調整路線、碉堡與行營的位置、地形。
  3. 最多 3 輪；還不行就回報。

## 7. 風險

| 風險 | 處理 |
|---|---|
| 防護格讓和棋變多 | P2 先在舊地圖上量；明顯變多時先回報 |
