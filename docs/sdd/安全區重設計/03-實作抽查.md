### 坦克撞雷（規格 F6）

- 照規格改成「坦克撞雷就死」後，只剩工兵能排雷，雷區打不開。擴充版-0 的和棋從 7% 升到 17%，對局從 122 手拖到 184 手。
- 已回報，使用者選「另外補排雷手段」。測了五種做法（各 60～80 盤），採用「工兵 4 → 6、連長和排長各 2 → 1、總兵力不變」：
  - 擴充版-0：先手 50%、和棋 8%、132 手。
  - 擴充版-1：先手 45%、和棋 9%、142 手。
- 舊棋譜照舊兵力（`countPreV3`）和舊規則重播。

## 地圖（規格第 4 節）

5 張全部手工設計，雙方鏡像（兩國換軌除外）。地圖檢查兩版都通過。調整了 3 輪：

| 地圖 | 擴充版-0 先手／和棋 | 擴充版-1 先手／和棋 | 主題地形 |
|---|---|---|---|
| 標準 | 53% / 9% ✓（120 盤） | 42% / 13% ✓ | 森林、平原、碉堡 |
| 兩國換軌 | 53% / 5% ✓ | 58% / 15% ✓ | 換軌站每盤 3～5 次 |
| 偏遠平原 | 40% / 8% ✓（120 盤） | 53% / 7% ✓ | 坦克衝刺 3 格、村莊 |
| 沼澤森林 | 43% / 5% ✓（120 盤） | 40% / 8% ✓（120 盤） | 沼澤、森林 |
| 山地 | **33% / 13% ✗**（120 盤） | 42% / 13% ✓ | 窄軌 |

- **爆破、走出大本營**：每張地圖每盤都有用到。爆破 1.5～5.5 次，走出大本營 0.2～1.2 次。
- **調整過程**：
  - 第 1 輪：山地是 7% / 82%，中路被高山擋住，兩翼又是窄軌。第 2 輪改成 4 座山、中路窄軌、兩翼標準軌。
  - 沼澤森林：前線那格沼澤移到後面，先手不再吃虧。
  - 標準地圖、兩國換軌的平原只有零星 3 格，主題是「右路暴露」，不是坦克衝刺，所以統計不再對這兩張檢查衝刺 3 格。
- **△ 未達標**：山地在擴充版-0 先手只有 33%，防守地形讓先攻的一方吃虧。第 3 輪改成只留前線 2 座山，兩版反而都變差（36～37% / 17～19%），所以退回第 2 輪。3 輪已用完，照規格回報，待決定。
