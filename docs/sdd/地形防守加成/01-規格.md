# 擴充版-1 地形防守加成＋自查問題：規格（SDD 第 1 步）

狀態：2026-10-03，等你拍板。標 ⚑ 的地方等你拍板，括號裡是我的建議。

## 0. 需求

- 你提的：「一版改成各地形有防守加成」。
- 這份也收進我自己查到的問題（§2）。

## 1. 擴充版-1：地形防守加成

### 1.1 規則（只有一句）

> **守方等級＝棋子等級＋所在格子的防守值。** 被攻擊、被狙擊時都用這個等級比；攻擊方站在哪裡不影響。

| 地形 | 防守值 | 現實理由 |
|---|---|---|
| 一般格、平原、大本營、鐵路 | 0 | 沒有掩護 |
| 森林 | +1 | 樹木掩護 |
| 村莊 | +1 | 建築掩護 |
| 行營 | +1 | 壕溝 |
| 碉堡 | +2 | 混凝土，最堅固 |
| 沼澤 | −1 | 陷在泥裡，難以抵抗 |

### 1.2 取代哪些擴充版-0 的規則

- **防護格「打不到」**：擴充版-1 拿掉，改成上表的加成。行營、碉堡裡的棋都打得到，只是比較難打。
- **工兵爆破**：保留，相鄰才能炸。炸掉後這格變一般格，加成歸零。森林、村莊是天然地形，不能炸。
- **狙擊**：照舊不能狙擊隱蔽格（森林、村莊），屬於視線規則。
  - ⚑ 行營、碉堡現在可以被狙擊了嗎？
  - 建議：**可以**，用加成後的等級和營長比。這樣防護格在擴充版-1 就沒有任何例外。

### 1.3 加成只在比等級時用

- 炸彈：照舊同歸於盡。所以炸彈是攻堅手段。
- 地雷：照舊只有工兵能排。
- 軍旗：照舊被攻擊就輸。
- 間諜刺殺司令：照舊成功，刺客不怕掩護。
- 同級（加成後）：雙方都移除，照原規則。

### 1.4 要拍板的地方

| ⚑ | 問題 | 建議 |
|---|---|---|
| 1 | 防守值 | 照 §1.1 的表 |
| 2 | 沼澤 −1 要不要 | **要**：「陷在泥裡」很直覺，也讓沼澤除了翻倒以外多一個缺點 |
| 3 | 翻倒的棋有沒有加成 | **有**：規則一致，不多加例外；翻倒是「停下重整」，不是「離開掩護」 |
| 4 | 防護格可以被狙擊 | **可以**（§1.2） |
| 5 | 擴充版-0 | 不變：防護格打不到，沒有等級加成 |

### 1.5 畫面

- 選了棋、可攻擊的敵棋在有加成的格子時，在格子角落標「守+1」「守+2」「守−1」。
- 地形一覽、規則頁寫出防守值。
- 實體棋盤：地形印在棋盤上，比大小時加上去即可，不需要新配件。

### 1.6 對遊戲性的影響

- 防守變強，對局可能拉長，要跑平衡。
- 碉堡、行營不再無敵，「躲著不出」的戰術變弱，可能反而縮短對局。
- 統計跑兩個版本：擴充版-0 應該不受影響；擴充版-1 要合格，不合格就調防守值。

## 2. 我自查到的問題

| # | 問題 | 證據 | 建議 |
|---|---|---|---|
| P1 | **AI 爆破後很少接著攻擊** | 追蹤 12 盤：只有約 20% 的爆破在 6 手內有棋攻擊那格 | AI 只在**有棋下一手能攻擊而且大概會贏**時才給爆破加分；沒有就不炸，省得工兵曝光 |
| P2 | **兩份「最強佈局」已經過時** | 都是在舊爆破規則下搜出來的；擴充版-1 的預設佈局也是它 | 規則改完後重新搜尋；預設佈局一起更新 |
| P3 | 「偵察」這顆棋和「偵察」這個動作同名，戰報寫成「…的偵察」「偵察 我方… 偵察 …」，讀起來混亂 | 剛才瀏覽器實測的戰報：「→ 我方 3列6欄 的偵察」 | ⚑ 棋名改成「**偵察兵**」（建議），舊佈局檔的「偵察」照樣讀得懂（已有別名機制） |
| P4 | 空降時不知道會不會被擊落 | 對方防空炮是明棋時，你看得到它，卻要自己數距離 | 選傘兵時，**已知**（明棋）防空炮看得到的落點標「會被擊落」；不是明棋的不標，避免洩漏資訊 |
| P5 | 兩國換軌（兩版）先手勝率偏低 | 本次統計：38%、35%，差 2～5 個百分點 | 先加跑到 200 盤確認是不是誤差；是真的偏低再調地圖 |
| P6 | 引擎的「比等級」函式只看地圖、不看局面 | 地形加成要知道這格有沒有被炸毀（局面資料）| 實作時改成傳入局面，第 2 步寫細節 |

## 3. 驗收

- **測試**：
  - 每種地形的加成正確。
  - 炸毀後加成歸零。
  - 炸彈、地雷、軍旗、間諜照舊。
  - 翻倒時照樣有加成（若 ⚑3 通過）。
  - 狙擊用加成後的等級（若 ⚑4 通過）。
  - 擴充版-0 完全不變：回歸逐手一致。
- **P1**：追蹤統計中，爆破後接著攻擊的比例明顯提高；和棋率不上升。
- **P3**：舊佈局檔、舊棋譜裡的「偵察」照樣讀得懂。
- **P4**：只有明棋防空炮的範圍會標示。
- **平衡**：全部地圖、兩版各跑 60 盤；兩國換軌加跑到 200 盤。
- **瀏覽器實測**：守方加成標示、空降擊落提示、規則頁、主控台沒有錯誤。
