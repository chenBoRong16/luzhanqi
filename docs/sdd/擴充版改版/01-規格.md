## 1b. 實體棋盤相容（兩個擴充版都必須做到）

規則用到的每一種狀態，都要能從棋盤上看出來，不靠玩家記憶、不靠紙筆記數。**不能有數值計算**，例如血量、傷害、護甲減傷（`功能.md` 的反例：「扣 37 點、再算護甲減傷」）。對撞只能是比等級、或固定的剋制關係。

| 狀態 | 棋盤上怎麼表示 |
|---|---|
| 棋的位置、所屬方 | 棋子本身 |
| 被揭露的棋（偵察、雷達、司令陣亡亮旗、狙擊失敗） | **翻成明棋**：正面朝上，之後一直公開 |
| 暫停一回合（走進森林、空降落地） | **翻倒**：棋子橫放，到該方下一回合結束時扶正 |
| 傘兵已空降 | 棋子上放「已空降」小標記（每顆傘兵一生只能空降一次） |
| 斷橋 | 在橋上放「斷橋」標記 |
| 連續無對撞手數（判和） | 棋盤邊緣印 0～80 的計數軌，放一個指示物；發生對撞就歸零 |
| 輪到誰 | 輪流下，不需要額外標記 |
| 碉堡加級（擴充版-1） | 看棋子是否站在碉堡格上，不需要額外狀態 |
| 狙擊（擴充版-1） | 比較對象固定是營長，不需要計算；失敗就翻成明棋 |

- 對撞判定和原版一樣需要裁判（或雙方互報），這是陸軍棋本來就有的玩法，不算額外狀態。
- 「自動推測」「標記敵棋」屬於介面輔助，不是規則，不受這條限制。
- **電腦版要用同一套呈現**：明棋、翻倒、已空降、斷橋、計數軌都畫在盤面上，畫面上看到的就是實體棋盤會看到的。
- 本輪**不做**可列印的棋盤或棋子檔案；如果需要，另外開一輪。

**不做**
- 兵力點數制佈陣（已封存）
- 戰爭迷霧
- 線上對戰
- 圖片或音效素材
- 修改 `功能.md`

## 4. 系統功能（S4 只有擴充版，其餘三版都有）

| 代號 | 內容 |
|---|---|
| S1 | **作弊功能分別開啟**：無限回合、上帝視角、添加棋子、刪除棋子、拖曳搬動、交換兩邊棋盤、**無視佈局條件**、悔棋，各自獨立開關。<br>添加、刪除、拖曳可以同時開：拖曳＝搬動；點空格＝添加；點棋子＝刪除。三項都關時，點擊回到一般操作。<br>上帝視角底下有子開關「餵給己方 AI」。<br>**無視佈局條件**：開啟後，匯入佈局檔（我方或敵方）和佈陣時互換，都不再檢查佈陣規則和棋子數量。軍旗不在大本營、地雷在前線、棋放在行營、棋數不對都允許。只檢查檔案格式：列數、欄數、棋名要認得 |
| S2 | **查看和輸出複盤**：對局中或結束後可以逐手回放、倒退、跳到任一手。可匯出（含複盤中正在看的那份）、匯入棋譜，內容包括雙方開局佈局、規則組、每一手、作弊動作 |
| S3 | **統計**：對局結束時顯示每種棋的擊殺與陣亡，以及各新機制的使用次數 |
| S4 | **規則開關**：每條擴充規則都能單獨開關。佈陣階段可改，開戰後鎖定，設定記在瀏覽器裡。預設全開 |

| S5 | **標示 AI 建議（開關）**：打開後，每次輪到你，盤面自動標出「幫我下的電腦」建議的下一步（建議移動的棋、目標格）。只是標示，照不照著走都可以。難度跟著「幫我下的電腦」；上帝視角餵給己方 AI 時，建議也用真實棋種。同一個局面只算一次，不會閃動 |

- AI 四級難度（簡單、中等、困難、最難）、觀戰、標記敵棋、佈局檔匯入匯出，都沿用現有功能。
- 原本的「建議下一步」按鈕由 S5 取代。

| S6 | **電腦代走一步**：輪到你時，按一下由「幫我下的電腦」替你走（可以悔棋）。和 S5 並存 |

## 5. 打架的地方，先拍板

| # | 衝突 | 決定 |
|---|---|---|
| C1 | 規則開關會改變棋子組成，但佈局檔要求固定棋數 | 佈局檔多存 `rules`。匯入時用檔案的規則組檢查；不同時提示一鍵切換。沒有 `rules` 的舊檔＝舊兵力、新規則全關 |
| C2 | 最強佈局要對應哪一組規則 | 各版的預設規則組（全開） |
| C3 | 最強佈局怎麼存 | 兩版各一份：`我個人/擴充版-0最強佈局.json`、`擴充版-1最強佈局.json`。現有的 `擴充版最強佈局.json` 移到 `_備份/01-舊版/我個人/` |
| C4 | 現在的「擴充版」資料夾 | 改名為 `擴充版-0`。首頁改成三張卡片。舊佈局檔的 `variant: "expanded"` 視為擴充版-0 |
| C5 | 新規則可能讓 AI 難度順序亂掉 | 新規則 AI 都要會用；兩個擴充版各自重驗 |
| C6 | 推理遇到新棋、新地形 | 加入推理。例如碉堡上的棋輸了，代表對方至少高兩級；狙擊失敗代表目標至少是營長，或是炸彈、地雷、軍旗 |
| C7 | 複盤和作弊 | 作弊動作也記入棋譜，回放時重現並標示【作弊】；悔棋會截斷棋譜 |
| C8 | 複盤時能不能看到對方的棋 | 對局中複盤：維持你當時的視角（看不到對方）。結束後複盤：全部明牌 |
| C9 | 一格有多種動作（狙擊、偵察、攻擊、炸橋、移動） | 沿用「要做什麼？」選單 |
| C10 | 無視佈局條件後，對手會依「軍旗一定在大本營、地雷一定在後兩列」推理，結果是錯的 | 用了違規佈局的那一方，所有棋的開局推理設為「什麼都有可能」，AI 推理才不會壞掉 |
| C11 | 違規佈局下的勝負 | 有多面軍旗時，奪到任一面就勝；沒有軍旗時，只能靠「對方無棋可動」取勝。其他規則照常，例如大本營裡的棋不能動 |
| C13 | 「翻成明棋」對雙方公開，和原本「只有偵察方知道」不同 | 採用翻成明棋。對被偵察的一方本來就沒有秘密（自己的棋自己知道），兩者只差在第三方觀戰，不影響對局 |
| C14 | 工兵在鐵路轉彎、坦克走兩格，會讓對方推出棋種 | 這是玩家自己的推理，不是規則狀態，不必翻成明棋；電腦版的自動推測照舊 |
| C15 | 某一方能動的棋全部翻倒時，會被判「無棋可動」而輸掉 | 改成**這回合跳過**；翻倒照常在該方回合結束時扶正。只有沒有翻倒的棋也動不了時，才判無棋可動 |
| C12 | 違規佈局和其他功能 | 違規佈局可以匯出、存成棋譜和複盤，檔案會標記 `illegal: true`。**最強佈局和預設佈局必須合法**。開關關掉後，匯入違規檔會被拒絕，並提示要先開啟 |

## 6. 驗收

- `node tests/test.js` 全過；每條新規則、新地形、作弊開關各至少 1 項測試；違規佈局能載入、能下完一盤、AI 不會出錯
- `node tests/regress-classic.js`：24 盤和基準完全一致
- 兩個擴充版各跑 60 盤（最難對最難）
  - 先手勝率在 40%～60% 之間
  - 和棋率 15% 以下
  - 主動機制（空降、偵察、坦克兩格、狙擊）每盤 ≥ 0.3 次
  - 炸橋 ≥ 0.1 次
  - 被動機制（森林進入、雷達揭露、碉堡防守）每盤 ≥ 0.3 次
- 實體相容抽查：兩個擴充版的每條規則，都能在 §1b 的表裡找到對應的棋盤表示；引擎裡不存在 §1b 以外的規則狀態，也沒有數值計算
- AI 難度：**本輪只要求「最難」打贏「簡單」**（得分率高於 50%）；四級完整排序（相鄰都高於 50%）延到下一輪再調
- 佈局檔和棋譜匯出再匯入，結果完全相同；複盤最後一手的盤面和實際對局相同
- 三版都要在瀏覽器實測，主控台沒有錯誤
