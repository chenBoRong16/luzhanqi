- **規則狀態**：棋子位置、所屬方、棋種、`faceUp`、`stunned`、`dropUsed`、`S.broken`、`S.quiet`、輪到誰、勝負。

## 5. 偏離與待辦

- **AI 四級完整排序延後**（使用者指示）：本輪只驗「最難打贏簡單」。擴充版「最難對困難」目前約 47～52%，之後用 `tests/tune-hardest.js` 再調。
- 依計劃風險項調整過 AI：炸橋原本每盤 0 次，加了「炸彈守橋頭」評分後達 0.5 次。
- 最強佈局是「電腦對電腦、對手隨機佈局」下的結果，不保證對真人也最強。
