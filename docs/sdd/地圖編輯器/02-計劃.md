# 音效與地圖編輯器：計劃（SDD 第 2 步）

狀態：**第 1 版（2026-10-02，對應規格第 5 版）**，等你點頭進入第 3 步。

規格的 ⚑ 一律照建議：
- 音量：聲音、音樂各一條滑桿，外加總靜音。
- 音樂分佈陣、對戰、結束三段情境；三版各一套主題。
- 「其他」區域先做山地。
- 地圖大小：7～11 欄、6～9 列。
- 預設鏡像對稱。
- 地圖可選音樂主題。
- 內建範例地圖 5 張。
- 自訂地圖的最強佈局只提供短搜尋。

## 2. 地圖檔格式（`luzhanqi-map`）

```json
{
  "format": "luzhanqi-map", "version": 1,
  "name": "兩國換軌", "variant": "expanded0",
  "cols": 7, "rows": 7, "mirror": true, "music": "default",
  "cells": [
    ["...", "..."],
    ["...", "..."]
  ],
  "roadsRemoved": [[[0,1,2],[0,2,2]]],
  "rails": [{ "gauge": "std", "path": [[0,0,5],[0,0,4]] }],
  "crossings": ["rail","bridge","mountain","rail","mountain","bridge","rail"]
}
```

- `cells[方][列]` 是一個字串，每個字一格（列 0＝前線）：
  - `.` 一般站點
  - `營` 行營、`本` 大本營、`堡` 碉堡
  - `原` 平原、`村` 村莊、`林` 森林、`沼` 沼澤、`山` 高山
- `rails`：每段一條折線，格子以 `[方, 欄, 列]` 表示；軌距為 `std`（標準軌）、`wide`（寬軌）、`narrow`（窄軌）。
- `crossings`：每欄一個，`rail`、`bridge` 或 `mountain`。
- **地圖識別**＝名稱＋內容雜湊（FNV-1a，把地圖轉成固定格式的 JSON 後計算）。

## 3. 每檔責任

| 檔案 | 責任 |
|---|---|
| `map.js` | `mapFromConfig`、`geometryFromMap`（已試作）；`validateMap`（§規格 B6，回傳錯誤與格子）；`mapHash`；`mirrorMap`；`applyBrush`（區域筆刷，固定亂數種子，保證連通）；地圖檔讀寫 |
| `maps-builtin.js` | 5 張範例：標準、兩國換軌、偏遠平原、沼澤森林、山地。由標準地圖＋筆刷以固定種子產生；擴充版-0 版本不含碉堡 |
| `board-draw.js` | 依盤面結構畫 SVG：格子、地形圖示＋花紋（黑白可辨）、公路、三種軌距線型、換軌站符號、過河口、斷橋。遊戲和編輯器都呼叫它 |
| `editor.js` | 工具列（格子筆刷、公路剪刀、鐵路筆＋軌距、過河口、區域筆刷）；鏡像；復原／重做（存快照）；即時檢查並標紅；匯入／匯出／存到瀏覽器；音樂主題；「試玩」 |
| `engine.js` | `buildVariant(cfg, rules, map)`：擴充版一律走地圖（不給地圖就用標準地圖）；原版維持舊建法。新地形規則見 §4 |
| `expanded-base.js` | 新規則開關：`gauge`（軌距規則）、`plain`、`village`、`swamp`（level 0）；高山、拆公路、過河口屬於地圖本身，不設開關 |
| `layout.js` | 佈局檔加 `map: {name, hash}`；匯入時不同就提示切換（找不到就提示匯入地圖）；`randomGrid` 避開高山、遵守沼澤限制、軍旗放任一大本營 |
| `record.js` | 棋譜存整張地圖；複盤用棋譜裡的地圖重建 |
| `ai.js` | 把「進入後會翻倒」的判斷從森林延伸到沼澤；村莊對高價值棋加一點遮蔽分；其餘靠引擎走法自然生效。**先讀懂使用者改的個性、smart 再動手** |
| `audio.js` | A2：只依公開資訊區分的事件音效、操作提示音、音量滑桿、三段情境音樂與主題、觀戰快速時每秒最多 3 個音效、複盤音效選項。B4：換軌、陷入沼澤、走進森林、坦克衝刺；編輯器操作音。**先讀懂使用者寫的合成器再擴充** |
| `ui.js` | 佈陣階段選地圖（內建、瀏覽器存的、匯入）；換地圖時重新掛載（和改規則同一套）；盤面繪製改用 `board-draw.js`；音量面板；圖例 |

## 4. 新地形規則怎麼接上引擎

| 規則 | 接在哪 | 作法 |
|---|---|---|
| 換軌站停下 | `geometryFromMap` 已在換軌站切開鐵路線 | 非工兵沿線走到線尾（換軌站）就自然停下。工兵 BFS 走到換軌站不再往外擴展（起點是換軌站時例外） |
| 窄軌最多 3 格 | `movesFor` 鐵路分支 | 窄軌線最多走 3 步；工兵 BFS 記錄已走的窄軌步數，超過 3 停止 |
| 坦克不上窄軌 | `movesFor` | 坦克不沿窄軌線走，也不展開窄軌的 BFS |
| 平原坦克 3 格 | `movesFor` 坦克分支 | 原本兩步 BFS 擴成三步，條件是起點、經過、終點全是平原；仍然只能轉一次彎、中間格要空 |
| 平原偵察 3、雷達 2 | 偵察分支、`updateRadar` | 範圍 BFS 深度，依**目標格**是否平原決定 |
| 村莊 | 偵察、雷達、空降目標排除村莊；`movesFor` 開頭：起點是村莊時只回傳公路一格 | |
| 沼澤 | `movesFor` 的 `consider`：坦克、炸彈不能以沼澤為目標（含攻擊）；空降排除；`applyMove` 的 `enter`：沼澤也翻倒；`placementError`：炸彈、地雷、軍旗、雷達站不能開局放沼澤 | |
| 高山 | `geometryFromMap` 不連任何邊；`placementError`：不能放棋 | |
| 規則開關關掉 | 地形照樣存在，效果不生效；`gauge` 關掉時，鐵路線不在換軌站切開，窄軌也不限格 | |

**桌遊條件**：以上判斷只看起點、目標、路徑格子的地形，以及數步數。不新增任何棋子或對局狀態欄位；T11 用 grep 再確認一次。

## 7. 風險

- **使用者改過 `ai.js`、`ui.js`、`audio.js`**：動手前完整讀過，只做必要的增改，保留個性、smart、音效既有行為。
- **`ui.js` 抽出繪製**：改動範圍大。抽完先確認三版畫面與改前一致，再加新地形。
- **大地圖讓 AI 變慢**：先量 11×9；超過 1 秒就把威脅快取延伸到新走法，必要時「最難」在大地圖減少評估範圍。
- **範例地圖不平衡**：T9 不達標時依 D10 先調地圖，再調規則數字（例如窄軌 3 格、平原 3 格）。
- **雙擊開啟（file://）讀不到 JSON**：內建地圖寫成 JS；使用者自己的地圖存在瀏覽器或用匯入。
