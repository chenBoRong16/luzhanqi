# A. 音效／音樂（三版）

## A1. 現況

`shared/audio.js` 用 Web Audio 合成，沒有外部音檔：
- **音效**：移動、對撞（勝、負、同歸）、勝負結果、開局、佈陣互換、介面提示。
- **背景音樂**，以及「聲音」「音樂」兩個開關（會記住）。

## A2. 補強

| 項目 | 內容 |
|---|---|
| 事件音效補齊 | 只依「公開資訊」區分（見 A3）：對撞的勝、負、同歸、奪旗；司令陣亡亮旗（低沉鼓聲）；翻成明棋（翻牌聲）；空降、偵察、狙擊、炸橋、翻倒、和棋、跳過回合。原版只會用到屬於原版的事件 |
| 作弊與操作 | 悔棋、作弊動作、匯入匯出、複盤翻頁用中性的輕提示音，音量較低 |
| ⚑ 音量 | （建議）「聲音」「音樂」各一條音量滑桿，外加一個總靜音；全部記住 |
| ⚑ 背景音樂情境 | （建議）佈陣、對戰、結束三段情境切換。原版、擴充版-0、擴充版-1 各一套主題；擴充版的地圖還能指定主題（見 B） |
| 觀戰與複盤 | 觀戰「快」速度時，音效限制每秒最多 3 次，避免噪音；複盤翻頁預設只出輕提示音，可以開「複盤播放事件音效」 |
| 首次互動 | 瀏覽器規定要先有使用者操作才能出聲；第一次點擊時自動啟動，不跳警告 |

## A3. 限制

- **桌遊條件**：音效只是電腦版的輔助，實體玩時沒有聲音也完全能玩。
- **不能洩漏規則外的資訊**：只依「你」在實體棋盤上也會知道的事發聲。例如你的棋撞到地雷，和輸給大棋，裁判都只說「你輸了」，所以兩者必須是同一個音效。只有勝負結果、明棋、看得到的動作（空降、炸橋等）可以有自己的聲音。
- 只用合成音，不加外部音檔（授權單純，`audio.js` 開頭已標註專案授權）。
- 音效、音樂只屬於介面：**不影響規則、AI、棋譜**。原版回歸 24 盤必須照舊一致。
- 沒有聲音的環境（例如 Node 測試、瀏覽器不支援）要能安靜跳過，不報錯。

## A4. 驗收

- 每種事件在瀏覽器裡各觸發一次，聽得出差別，主控台沒有錯誤。
- 音量、靜音、音樂開關重新整理後仍記得。
- 觀戰快速時不會連續爆音。
- 原版回歸、全部測試照過。

# B. 地圖編輯器（擴充版）

## B1. 設計原則（依優先順序）

**硬性條件**（一定要做到）：
1. **只用「能不能」和「走幾格」**：不改等級，不做數值計算。所以全部可以用在擴充版-0，也能做成實體棋盤。
2. **地形是固定的格子屬性**：對局中唯一會變的地形是斷橋（已有標記），其餘一眼看盤面就知道。
3. **符合桌遊條件**（`功能.md`）：每條規則在實體棋盤上都能靠「看盤面＋數格子」判斷，判斷依據只能是棋子所在格、目標格、路徑上的格子這些看得見的東西，不能有爭議；需要的狀態只能用既有配件表示（明棋、翻倒、已空降標記、斷橋標記、判和計數軌）。逐條檢查見 §B3e。
4. **地圖印得出來**：每張地圖都要能印成實體棋盤。地形用「圖示＋花紋」表示，黑白列印也分得清楚，不能只靠顏色。

**遊戲性**（優先於現實）：
5. **每種地形都要帶來取捨**：有好處也有代價，不能只是純加強或純減弱，否則大家只會繞開或只會搶。
6. **不能讓某一招穩贏**：例如鐵路一路直衝敵後、坦克無人可擋。模擬驗收（§B11）用先手勝率、和棋率、機制使用量來把關。
7. **少而好記**：每種地形最多 2～3 條效果。

**現實合理性**（軟性條件、加分項）：
8. 盡量讓規則說得出一句現實理由，方便理解。例如「坦克太重，窄軌載不動」。
9. 現實和遊戲性衝突時，**遊戲性優先**。必要時把規則簡化或改得不那麼寫實，並在說明裡註明「遊戲簡化」。

## B2. 範圍

**要做**
1. 地圖編輯器：兩個擴充版都能用，原版不能用。
2. 新地形：軌距（三種）、平原、村莊、沼澤、高山，連同既有的森林、碉堡。
3. 區域筆刷：偏遠平原、鄉村、沼澤地帶、森林地帶、山地（「其他」先放這一種，可再擴充）。
4. 地圖檔（匯入、匯出）、內建範例地圖、佈陣前選地圖。佈局檔與棋譜要記得用的是哪張地圖。
5. 地形相關的音效、音樂：見 §B4（建在 A 部分之上）。

**不做**
- 原版的地圖編輯
- 線上分享
- 圖片或錄音素材（照舊用 SVG 和 Web Audio 合成）
- 可列印棋盤檔
- 兵力點數制（已封存）

**預設地圖不變**：不選地圖時，用的就是現在的盤面。所以現有的佈局檔、棋譜、最強佈局、測試全部有效。

## B3. 地形與規則

### B3a. 鐵路軌距（「不同國家間運輸」）

| 軌距 | 規則 | 現實依據 |
|---|---|---|
| 標準軌 | 和現在一樣：直線任意格 | 大多數國家的幹線 |
| 寬軌 | 和標準軌一樣（只是軌距不同） | 部分國家採用寬軌，跨國要換軌 |
| 窄軌 | 一次最多走 3 格；**坦克不能上** | 窄軌載重小、速度慢，多用於山區、地方支線 |

**換軌站**：兩種軌距相接的格子。
- 沿鐵路移動到換軌站必須停下，下一回合才能換到另一種軌距繼續走。工兵也一樣。
- 現實依據：軌距不同，車廂過不去，要換車或換轉向架（例如中國與蒙古、俄羅斯邊境）。
- 實體棋盤：換軌站畫成特殊車站符號，不需要額外狀態。

⚑ 建議範例：每一方各自鋪一種軌距（例如我方標準軌、對方寬軌），過河的鐵路正好在國界換軌。這就是「跨國換軌」，讓鐵路突襲對方後方不再一路通到底。

### B3b. 格子地形

| 地形 | 規則 | 現實依據 | 擴充版-0 | 擴充版-1 | 狀態 |
|---|---|---|:-:|:-:|---|
| 一般站點 | 無 | | ✓ | ✓ | 現有 |
| 行營 | 裡面的棋不能被攻擊；開局空著 | 防禦工事 | ✓ | ✓ | 現有 |
| 大本營 | 軍旗只能放這；裡面的棋不能動 | 指揮部 | ✓ | ✓ | 現有 |
| **平原** | 好處：坦克的公路移動**整段路（含起點、終點）都是平原**時，可以一次走 3 格（否則照舊 2 格）。代價：**目標棋站在平原上**時，對方偵察的範圍是 3 格、雷達是 2 格（一般是 2 格、1 格） | 開闊地適合裝甲推進，但也無處躲藏 | ✓ | ✓ | 新 |
| **村莊** | 好處：裡面的棋不會被偵察、雷達揭露（可以被攻擊）；傘兵不能空降進村莊。代價：**起點在村莊**的棋，這一手只能走公路一格（不能直接上鐵路、坦克不能走兩格） | 建築物遮蔽視線；巷弄狹窄出不快 | ✓ | ✓ | 新 |
| 森林 | 好處：不能被偵察、雷達、狙擊。代價：走進去翻倒一回合 | 樹林好藏身但難行 | ✓ | ✓ | 現有 |
| **沼澤** | 代價：走進去翻倒一回合；鐵路不能鋪。好處（對守方）：坦克、炸彈進不來，傘兵不能空降，適合小棋據守 | 重裝備陷住；泥地無法著陸、無法鋪軌 | ✓ | ✓ | 新 |
| **高山** | 不能進入、不能放棋；公路、鐵路都不能經過 | 天然屏障 | ✓ | ✓ | 新（河界上原有的山統一成這一種） |
| 碉堡 | 防守時高一級 | 堅固工事 | ✗ | ✓ | 現有（等效等級，只有擴充版-1） |

### B3c. 連線與過河

| 項目 | 可以編輯的內容 | 現實依據 |
|---|---|---|
| 公路 | 相鄰格子之間的公路可以拆掉；行營斜線照舊自動產生 | 偏遠地區路網稀疏 |
| 鐵路 | 自由畫線（沿相鄰格子），每段選軌距；不能經過沼澤、高山 | |
| 過河口 | 每一欄可選：鐵路、公路橋（可炸毀）、山（不通） | |

### B3d. 區域筆刷（編輯工具，不是新規則）

框選一塊範圍後套用，之後可以逐格手改：

| 筆刷 | 效果 |
|---|---|
| 偏遠平原 | 大部分格子變平原；拆掉一部分公路；不留鐵路或只留窄軌 |
| 鄉村 | 散布村莊；公路保留；行營變少 |
| 沼澤地帶 | 約一半格子變沼澤，保證沒有被困死的格子 |
| 森林地帶 | 約一半格子變森林 |
| 山地（其他） | 散布高山，留出山口；鐵路改窄軌 |

- 「其他」先提供山地。⚑ 如果你還想要沙漠、城市、雪地等，請列出來，我照同樣原則（一句話的現實理由、只用能不能和走幾格）補規則。

### B3e. 桌遊條件逐條檢查

| 規則 | 實體棋盤上怎麼判斷 | 需要的配件 |
|---|---|---|
| 換軌站停下 | 看鐵路線樣式在哪一格改變（換軌站畫特殊車站符號） | 無 |
| 窄軌最多 3 格 | 數格子 | 無 |
| 坦克不能上窄軌、不能進沼澤 | 看線樣式、看格子圖示 | 無 |
| 平原坦克 3 格 | 看整段路的格子是否都是平原 | 無 |
| 平原偵察 3 格、雷達 2 格 | 看**目標**站的格子；數格子 | 無（數字印在圖例上） |
| 村莊不被偵察、不能空降、出發只走一格 | 看格子圖示 | 無 |
| 森林、沼澤翻倒一回合 | 棋子橫放 | 既有（翻倒） |
| 沼澤禁坦克、禁炸彈、禁空降、禁鋪軌 | 看格子圖示 | 無 |
| 高山不能通行 | 看格子圖示 | 無 |
| 拆掉的公路 | 盤面上就沒有那條線 | 無 |
| 炸橋 | 放斷橋標記 | 既有（斷橋） |
| 碉堡（擴充版-1） | 看格子圖示 | 無 |

結論：新增的規則都**不需要新配件**，也沒有任何數值計算。

## B4. 地形相關的音效與音樂

建在 A 部分之上（同一套合成器、同一組開關與音量）。

| 種類 | 內容 |
|---|---|
| 新事件音效 | 換軌（金屬撞擊）、陷入沼澤（悶響）、走進森林（沙沙）、坦克在平原衝刺（引擎聲）、炸橋（爆炸，若已有則沿用） |
| 編輯器音效 | 塗格子、畫鐵路、拆公路、復原；檢查不通過時一聲提示。音量比對局低 |
| ⚑ 背景音樂 | 地圖檔可選主題：預設、平原、沼澤、森林、山地。各主題換調式或節奏，沿用現有合成器；也可以設「跟預設相同」 |

- 不加外部音檔，以免授權問題。

## B5. 地圖大小與對稱

- ⚑ **大小**（建議：每方 7～11 欄、6～9 列可調，預設 7×7）。下限 7 欄保證比原版的 5 欄寬。
- ⚑ **對稱**（建議：預設鏡像，畫一邊另一邊自動跟著）。可以關掉做不對稱地圖，例如兩國不同軌距；會標示「不對稱」。

## B6. 地圖要能玩：存檔前檢查

存檔或試玩前自動檢查，不通過的格子標紅，並說明原因：

- 每方至少 1 個大本營。
- 每方可放棋的格子（扣掉行營、高山）夠放整支兵力；地雷、炸彈等有位置限制的棋也放得下（例如沼澤不能放炸彈）。
- 至少 1 個過河口。
- 每個可進入的格子，都能從己方大本營走公路連到對方半場（沒有孤島）。
- 鐵路不經過沼澤、高山；每段兩端都是相鄰格子。

## B7. 地圖檔與相容

- 新格式 `luzhanqi-map`：版本、名稱、大小、對稱與否、每格地形、拆掉的公路、鐵路（含軌距）、過河口、音樂主題。
- **佈局檔**多記地圖識別（名稱＋內容雜湊）。不同時提示切換地圖；沒有那張地圖就提示匯入。
- **棋譜**直接把整張地圖存進去，換台電腦也能複盤。
- **規則開關**：地圖決定「哪裡是什麼地形」，規則開關決定「效果開不開」。新地形各有一個開關；關掉的地形在盤面上當一般格子。
- ⚑ 內建範例地圖（建議 5 張）：
  - 標準（現在的盤面）
  - 兩國換軌
  - 偏遠平原
  - 沼澤森林
  - 山地

## B8. 編輯器介面

- 獨立頁面，首頁加卡片，可以選擇編輯擴充版-0 或擴充版-1 的地圖。
- **工具**：
  - 格子筆刷：選地形，點或拖曳塗格子
  - 公路剪刀
  - 鐵路筆：拖出一段，選軌距
  - 過河口切換
  - 區域筆刷：框選後套用
- **其他操作**：復原／重做、清空、套用範例、即時檢查、匯入／匯出、存到瀏覽器、音樂主題。
- **「試玩這張地圖」**：直接開到該版的佈陣畫面。
- 編輯器裡畫的樣子，就是對局時看到的樣子。地形說明以圖例和滑鼠提示呈現，內容是各地形的規則加一句現實理由。

## B9. AI 與最強佈局

- AI 依盤面連線計算，新地形接上規則就能用；個性、smart 判斷照常。另外補兩項評估：
  - 翻倒（沼澤、森林）的代價
  - 村莊的遮蔽價值
- 隨機佈局要跟著地圖走：避開高山，遵守沼澤限制，軍旗放在任一大本營，地雷圍旗。
- ⚑ **最強佈局**（建議：只維持兩張預設地圖的最強佈局。編輯器提供「為這張地圖搜尋佈局」，在瀏覽器背景跑短搜尋）。

## B10. 打架的地方，先拍板

| # | 衝突 | 決定 |
|---|---|---|
| D1 | 地圖可以改大小，但佈局檔、最強佈局都假設 7×7 | 佈局檔記地圖識別（§B7）；最強佈局只對預設地圖（§B9） |
| D2 | 規則開關和地圖都在決定地形 | 地圖決定位置，開關決定效果（§B7） |
| D3 | 實體棋盤相容（桌遊條件） | 見 §B3e：每條規則都靠「看格子＋數格子」判斷，不需要新配件；判斷依據都限定在起點、目標、路徑這些看得見的格子 |
| D4 | 擴充版-0 不能有等效等級 | 新地形全部只用「能不能」和「走幾格」；碉堡仍只在擴充版-1 |
| D5 | 不對稱地圖可能讓先手失衡 | 允許，但標示「不對稱」；統計驗收只對內建範例地圖 |
| D6 | 森林和沼澤都會翻倒，容易混淆 | 森林＝能藏身；沼澤＝重裝備進不去、不能空降、不能鋪軌。圖例並列對照 |
| D7 | 平原讓坦克變更強 | 坦克仍怕炸彈、地雷（破雷規則照舊）；平原上沒有遮蔽，容易被偵察 |
| D8 | 大地圖讓 AI 變慢 | 驗收一手 ≤ 1 秒（11×9、最難）；超過就擴大 AI 的威脅快取 |
| D9 | 新音效太吵 | 沿用 A 部分的音量與開關；編輯器音效音量較低；觀戰快速時限速（A2） |
| D10 | 現實合理性和遊戲性衝突 | 遊戲性優先（§B1 第 9 點）。例：寬軌在遊戲裡和標準軌完全一樣，只是為了做出跨國換軌，這是刻意的簡化；若模擬顯示某條地形規則讓先手失衡或沒人用，就改規則，不為了寫實而保留 |

## B11. 驗收

- 預設地圖下，現有測試全過；原版回歸 24 盤一致。
- 新規則各至少 1 項測試：
  - 三種軌距、換軌站停下、窄軌上限與坦克禁上
  - 平原坦克 3 格
  - 村莊遮蔽與禁空降
  - 沼澤翻倒、禁入、禁空降、禁鋪軌
  - 高山
  - 拆公路、自訂過河口
- 地圖檢查：每條規則各 1 個不合格的反例測試。
- 地圖檔、佈局檔（含地圖識別）、棋譜（含地圖）匯出再匯入，結果完全相同。
- 內建範例地圖各跑 60 盤（最難對最難）：先手 40～60%、和棋 ≤ 15%，該地圖的新地形每盤都有用到。
- 11×9 地圖：最難 AI 一手 ≤ 1 秒。
- 瀏覽器實測：編輯器每個工具、試玩、匯入匯出、地形音效與地圖音樂主題，主控台沒有錯誤。
- 桌遊條件：
  - 對照 §B3e 逐條確認，引擎裡沒有新的規則狀態。
  - 地圖黑白列印（瀏覽器列印預覽）時，各地形仍分得清楚。
  - 音效不洩漏資訊：撞雷和輸給大棋是同一個音效。
- 加分項：新規則的說明盡量附一句現實理由；做了「遊戲簡化」的地方要註明。

# C. AI 設置（三版）

需求：
> ai的設置，包含思考深度（越深思花越久時間）、個性等。

## C1. 現況

- 介面上，「對手」和「幫我下的電腦」各有兩項：
  - **難度**四級：簡單、中等、困難、最難。
  - **個性**七種：均衡、猛攻、穩守、衝鋒、護旗、試探、賭徒。
- 難度其實是一組參數：隨機性、攻擊、避險、護旗，以及 smart 加強判斷。
- AI 只看「這一步」：評估自己這手之後的局面與危險，沒有往下推演。一手約 0.01～0.02 秒，所以現在**沒有「想越久越強」這回事**。

## C2. 改成「AI 設置」

「難度」改名為 **AI 設置**。對手、幫我下的電腦各一組，內容如下：

| 設定 | 選項 | 說明 |
|---|---|---|
| **快速套用** | 簡單、中等、困難、最難 | 一鍵填入下面各項，`功能.md` 要求的「簡單／…／最難」由這裡提供。改了任一項後顯示「自訂」 |
| **思考深度** | 1～5 | 越深越強，也越花時間（見 C3） |
| **個性** | 七種（沿用） | 風格倍率，乘在下面的參數上 |
| 細項（進階，可收合） | 隨機性、攻擊性、避險、護旗：各一條滑桿；smart 開關 | 就是現在難度背後的那組參數，改成看得見、能調 |
| **思考時間** | 選深度時顯示「約幾秒」；每手下完顯示實際花了多久 | 讓「越深越久」看得見 |
| **長考上限** | 秒數（預設 15）或「不限」 | 見 C3 |

## C3. 思考深度：越深思越花時間

| 深度 | 做法 | 一手約多久（目標，7×7） |
|---|---|---|
| 1 即時 | 只看這一步（現在的做法） | 立刻（< 0.05 秒） |
| 2 看回應 | 我的候選手之後，再看對方最好的回應 | 約 0.2 秒 |
| 3 推演 | 從推理抽幾種「對方的暗棋可能是這樣」，各推演兩步再平均 | 約 1 秒 |
| 4 深推演 | 抽樣更多，前幾名候選手再往下多看一步 | 約 3 秒 |
| 5 長考 | 再加倍抽樣與候選手 | 約 8 秒 |

- **深度定的是「算多少」，不是「算幾秒」**：每一級是固定的推演量（抽幾種、看幾手、留幾個候選）。好處有兩個：
  1. 同樣的設置、同樣的局面，一定下出同一步，測試和複盤可以重現。
  2. 時間跟著電腦速度走：慢電腦上深度 5 就想更久，這正是「越深思越花時間」。
- 表上的秒數是目標，實作後依實測修正，並顯示在選單上。大地圖會更久，選單照實際地圖大小估。
- **長考上限**（可設定秒數，預設 15 秒，也可以選「不限」）：一手想到上限就用目前想到的最好一步，並在思考時間旁標「時間到」。預設值是避免慢電腦卡死的保險，平常不會觸發；設得比深度需要的時間短，就等於用秒數換強度。
  - 測試與統計一律用「不限」，結果才能重現。

## C4. 想的時候不能卡住畫面

- 深度 2 以上分段計算，算的時候盤面、按鈕照常能用，並顯示「電腦思考中…」與經過秒數。
- 加一個「**立刻下**」按鈕：中途按下，就用目前最好的一步。
- 會用到 AI 的地方都適用：對手、觀戰雙方、「電腦代走一步」、「標示 AI 建議下一步」。
- 觀戰：雙方可以設不同深度。觀戰速度改成「每手至少停多久」，電腦想得比這久時，就等它想完。

## C5. 公平與桌遊條件

- **只用自己看得到的資訊**（沿用）：推演時對方的暗棋一律用推理出的可能性抽樣，不偷看。
- 「上帝視角餵給己方 AI」照舊只對該方有效；開了就不用抽樣，直接用真實棋子推演。
- 設置記在瀏覽器裡；不寫進棋譜，不影響規則。AI 只是電腦對手，與實體棋盤無關。

## C6. 相容

- **深度 1** 加上現在的參數，結果要和現在**逐手相同**，原版與擴充版的回歸測試照舊有效。
- 快速套用的對應：

| | 思考深度 | 其他參數 |
|---|---|---|
| 簡單 | 1 | 沿用現在的簡單 |
| 中等 | 1 | 沿用現在的中等 |
| 困難 | 2 | 沿用現在的困難 |
| 最難 | 3 | 沿用現在的最難（含 smart） |

  - 深度 4、5 不放進快速套用，想要更強的人自己調。這樣「最難」一手約 1 秒，觀戰整盤約 2～3 分鐘，還能接受。
- 舊存檔裡記的「難度」自動換成對應的快速套用。

## C7. 打架的地方，先拍板

| # | 衝突 | 決定 |
|---|---|---|
| D11 | 「越深越久」和「介面不能卡」 | 分段計算＋「立刻下」按鈕（C4） |
| D12 | 用秒數限制會讓結果每次不同，測試無法重現 | 深度定推演量，不定秒數；長考上限可設定，預設很寬只當保險，測試用「不限」（C3） |
| D13 | 深度高的推演要猜對方暗棋，可能變成偷看 | 只從推理可能性抽樣；上帝視角照舊要玩家自己開（C5） |
| D14 | 驗收要跑很多盤，深度高時太慢 | 強弱驗收只比相鄰深度、在 7×7 跑；深度 4、5 只跑少量盤數並看趨勢（C8） |

## C8. 驗收

- 深度 1 的回歸測試：原版、擴充版逐手一致。
- **越深越強**：同參數下，深度 2 對 1、3 對 2，各打 60 盤以上，得分率都高於 50%。深度 4 對 3、5 對 4 各打 20 盤，得分率不低於 50%（趨勢）。
- **越深越久**：實測每一級的平均時間要逐級增加，選單上的估計和實測相差在 2 倍以內。
- 快速套用「最難」對「簡單」得分率高於 50%（沿用上一輪的要求）。
- 11×9 地圖、深度 3：一手 ≤ 3 秒。
- 瀏覽器實測：
  - 快速套用、細項滑桿、「自訂」顯示、思考時間顯示都正常。
  - 長考上限設短（例如 1 秒）時，深度 5 到時就下，並標「時間到」。
  - 深度 5 思考時畫面不卡，「立刻下」有效。
  - 主控台沒有錯誤。
