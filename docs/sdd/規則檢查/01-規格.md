# 規則檢查與修正：規格（SDD 第 1 步）

狀態：**第 2 版（2026-10-03）**：已核可，B1～B4 都照建議（你說「第二步」，沒有另外修改）。

## 0. 依據與範圍

- 需求：「檢查規則，若有問題就修，可增改刪規則。」
- 檢查範圍：
  - 三份規則文件：`docs/rules.md`、`rules-expanded-0.md`、`rules-expanded-1.md`。
  - 規則說明頁。
  - 引擎實作：佈陣、走法、對撞、偵察、雷達、空降、狙擊、炸橋、地形。
- 判斷標準，依優先順序：
  1. 規則前後一致，文件和程式一致。
  2. 沒有讓某一招穩贏或拖成無限和局的漏洞。
  3. `功能.md` 的條件：
     - 須兼容做成棋盤遊戲，只看格子和步數。
     - 擴充版-0 不能有等效等級規則。
  4. 現實合理性（加分）。
- **原版**：沒發現問題，不動。

## 1. 發現的問題

### A. 規則漏洞（建議直接修）

| # | 問題 | 怎麼發生 | 修法 | 現實理由 |
|---|---|---|---|---|
| A1 | **坦克能跳過沼澤** | 坦克走兩格時，只檢查中間格有沒有棋，沒檢查是不是沼澤 | 坦克走兩格（和平原三格）時，**路上每一格**都不能是沼澤 | 重裝備陷進沼澤就過不去，穿過也算進去 |
| A2 | **坦克能開局放在沼澤** | 開局限制只禁了炸彈、地雷、軍旗、雷達站 | 坦克也不能開局放在沼澤 | 和「坦克進不去沼澤」一致 |
| A3 | **狙擊能打村莊裡的棋** | 村莊和森林一樣不會被偵察、雷達揭露，但狙擊只排除森林 | 狙擊不能以**村莊**裡的棋當目標 | 建築物擋住視線；和偵察、雷達一致 |
| A4 | **自訂地圖可能被炸成兩半** | 地圖檢查只要求至少 1 個過河口；如果全是公路橋，炸光後雙方完全隔開，落後的一方可以靠炸橋拖成和局（關掉和局條件時就永遠不會結束） | 地圖檢查改成：**至少 1 個鐵路過河口**（內建地圖都符合） | 不是遊戲規則，是地圖規則 |

### B. 規則設計問題（等你拍板）

| # | 問題 | 建議 |
|---|---|---|
| B1 | **坦克兩步經過森林不會翻倒**：停在森林會翻倒，但從中間穿過去沒事 | **決定**：坦克走兩格時，中間那格**不能是森林**，「整段路要暢通」。標準地圖有森林，所以擴充版回歸基準要重錄 |
| B2 | **沼澤讓大子幾乎無敵**：炸彈不能進沼澤、也不能攻擊沼澤裡的棋，所以司令、軍長躲進沼澤後，只剩對方司令（同歸）或間諜（只能殺司令）對付得了。沼澤森林地圖的和棋率偏高（18～23%），這可能是原因之一 | **決定**：**炸彈可以進沼澤**（照樣翻倒），也可以開局放在沼澤；只有坦克進不去。現實理由：炸彈是步兵背的炸藥，不算重裝備 |
| B3 | **窄軌只有壞處**：窄軌最多 3 格、坦克不能上，沒有任何好處；山地地圖的窄軌只有 1 段、每盤使用 0 次。這違反「每種地形都要帶來取捨」的原則 | **決定**：新增**窄軌可沿線轉彎**：在窄軌上，任何棋（坦克除外）都可以順著窄軌轉彎走，合計最多 3 格。山地地圖改成有一條像樣的窄軌支線。現實理由：火車本來就順著鐵軌走；窄軌彎道多，正適合山區。桌遊：沿線數格子 |
| B4 | **平原坦克 3 格幾乎沒人用**（每盤 0.03 次）：條件是起點、終點和路上都是平原、中間要空，偏遠平原地圖的平原路網不夠連續 | 規則不改，改地圖：偏遠平原的平原區公路保持完整，讓坦克有地方衝。改完重跑統計 |

### C. 文件用詞

| # | 問題 | 修法 |
|---|---|---|
| C1 | 規則寫「坦克…只能在第二格攻擊」，容易誤解成坦克不能攻擊相鄰的棋 | 改成「一般走法照常（含攻擊相鄰的棋）；**另外**可以一次走兩格，中間那格要空、不能是沼澤（森林依 B1），攻擊只能發生在第二格」 |
| C2 | 「走進森林翻倒」沒寫清楚沿鐵路**經過**森林算不算 | 寫清楚：**停在**森林才翻倒；沿鐵路經過不算。沼澤沒有鐵路，不會發生 |
| C3 | 狙擊不能打的目標只寫了行營、森林 | 加上村莊（A3） |

## 2. 不改的（檢查過，沒問題）

- **偵察**：
  - 站在森林、村莊裡可以偵察外面。
  - 森林、村莊裡的棋不能被偵察。
  - 偵察時自己翻成明棋。
  - 前後一致。
- **雷達**：範圍、平原 2 格、森林與村莊看不到，都和偵察一致。被狙擊打得掉（等級最低）。
- **空降**：不能進行營、大本營、沼澤、村莊、防空炮旁邊。從村莊出發不能空降。
- **翻倒**：翻倒那一手到自己下一回合結束都不能動；全部翻倒時跳過一回合。
- **換軌站、窄軌上限、坦克不上窄軌**：工兵也遵守。
- **碉堡（擴充版-1）**：狙擊也算加級，一致。
- **原版**：對撞順序、佈陣、行營、大本營都符合文件。

## 3. 限制

- **桌遊條件**：所有修改都只看格子種類和步數，不加新狀態、不加數值計算。B3 的「沿窄軌轉彎」是數沿線格子。
- **擴充版-0**：沒有加任何等效等級規則。
- 每一條修改都要能用規則開關關掉嗎？
  - 不需要：A、C 是修正。
  - B1～B3 照現有的地形開關走：關掉「沼澤」「森林」「軌距」就沒有這些效果。

## 4. 驗收

- **測試**（每條 1 項以上）：
  - 坦克不能經過沼澤（含平原三格）。
  - 坦克不能開局放在沼澤。
  - 狙擊不能打村莊。
  - 沒有鐵路過河口的地圖檢查不通過。
  - 照拍板結果：B1 森林、B2 炸彈進沼澤、B3 窄軌轉彎。
- **回歸**：
  - 原版回歸逐手一致。
  - 擴充版回歸：B1 會改變標準地圖的坦克走法。若採 B1，以修改後版本重錄基準，舊基準留存。
- **統計**：受影響的範例地圖（沼澤森林、山地、偏遠平原、標準）各重跑 60 盤，和修改前比較和棋率與機制使用量。目標照舊：先手 40～60%、和棋 ≤ 15%，地形每盤都有用到。
- **文件**：三份規則文件、規則說明頁、地形圖例同步更新，修改處附一句現實理由。
