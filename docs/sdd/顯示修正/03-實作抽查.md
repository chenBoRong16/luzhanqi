## 和計劃不同的地方

- 「爆破」「上一手：偵察」這類小標籤，計劃寫用 CSS 的 `::after`。實作時發現會被別的樣式蓋掉：
  - 被爆破過的格子本身會寫「已炸毀」。
  - 空的行營同時可移動（畫可走點）、可爆破。
- 所以改用格子裡真的 `<span>` 元素，兩種標示可以同時出現。
