# 顯示修正：規格（SDD 第 1 步）

狀態：2026-10-03，等你拍板。標 ⚑ 的地方等你拍板，括號裡是我的建議。

## 0. 起因與範圍

- 起因：一顆棋能做好幾種動作時，AI 建議分不出是哪一種。例如工兵旁邊是空的對方行營，可以「移動」也可以「爆破」，兩者都顯示成「工兵（2,2）→（1,1）」。
- 範圍：查了所有會顯示「動作」或「位置」的地方。
  - AI 建議列、走棋提醒。
  - 盤面標示：建議、可走的格子、上一手。
  - 複盤說明。
- 只改顯示，不動規則、AI、棋譜格式。

## 1. 查到的問題

| # | 位置 | 問題 |
|---|---|---|
| D1 | AI 建議列、走棋提醒的「AI 會走…」 | 只寫「棋（欄,列）→（欄,列）」，不寫動作：移動和爆破看起來一樣；偵察、狙擊、炸橋明明不移動，箭頭卻像要走過去 |
| D2 | 盤面上建議的目標格 | 只寫「建議」，不寫動作 |
| D3 | 選了工兵之後，可爆破的格子 | **沒有任何標示**，滑鼠也不是手指形狀。對方棋站在防護格裡時（只能爆破、不能攻擊），你完全看不出可以爆破 |
| D4 | 複盤說明 | 爆破顯示成英文「blast」；開戰後用作弊改和局條件的那一步，說明是空白 |
| D5 | 位置寫法不一致 | 建議寫「（欄,列）」，複盤寫「下方 列-欄」，順序相反，也不寫是哪一方 |
| D6 | 上一手的標示 | 偵察、狙擊、爆破、炸橋時棋子沒有移動，但起點、終點照樣標成「從這裡走到那裡」 |

## 2. 修法

### 2.1 動作一律寫出來（D1、D2、D4）

**文字**：

| 動作 | 寫法 |
|---|---|
| 移動 | 師長 我方 5列2欄 → 我方 4列2欄 |
| 攻擊 | 師長 我方 5列2欄 攻擊 對方 1列2欄 |
| 爆破 | 工兵 對方 2列3欄 爆破 對方 2列2欄 |
| 偵察、狙擊 | 偵察 我方 1列4欄 偵察 對方 1列4欄 |
| 空降 | 傘兵 我方 4列3欄 空降到 對方 2列6欄 |
| 炸橋 | 炸彈 我方 1列2欄 炸橋 |

- **盤面**：目標格的小標籤改成「建議移動」「建議攻擊」「建議爆破」「建議偵察」「建議狙擊」「建議空降」「建議炸橋」。
- **複盤說明**：補上「爆破」和【作弊】改和局條件（寫出改成幾手，或「不判和」）。

### 2.2 可爆破的格子要看得到（D3）

選了工兵以後，可爆破的格子畫上和「炸橋」同類的小標籤「爆破」，滑鼠也變成手指形狀。

### 2.3 位置寫法統一（D5）

- ⚑ 統一成「**我方／對方 第幾列第幾欄**」（建議），例如「對方 2列3欄」。
  - 列從前線算起，和規則文件、棋盤圖的編號一致。
  - AI 建議、走棋提醒、複盤都用這一種。
  - 觀戰兩個 AI 對下時沒有「我方」，改寫「下方／上方」。

### 2.4 上一手標示（D6）

- ⚑ 棋子沒有移動的動作（偵察、狙擊、爆破、炸橋），起點不標「從這裡出發」，終點標出動作名稱，例如「偵察」（建議：**要**）。
- 移動、攻擊、空降照舊。

## 3. 驗收

- **測試**：動作文字的函式。
  - 每一種動作都寫得出正確的文字。
  - 同一格的「移動」和「爆破」文字不同。
  - 複盤說明不再出現英文或空白。
- **瀏覽器實測**：
  - AI 建議出現爆破、偵察、空降時，文字和盤面標籤正確。
  - 選工兵時，可爆破的格子看得到。
  - 複盤的爆破、改和局步驟說明正確。
  - 上一手是偵察時的標示。
  - 主控台沒有錯誤。
- 原版、擴充版回歸逐手一致（只改顯示）。
