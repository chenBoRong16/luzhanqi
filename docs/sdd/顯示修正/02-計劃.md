## 2. 做法

### 2.1 共用文字函式（`record.js`）

```
posText(V, n, me)
  → "我方 2列3欄" / "對方 2列3欄"   （me＝視角那一方）
  → me 為 null 時（觀戰）："下方 2列3欄" / "上方 2列3欄"
  列從前線算起：nd.row + 1；欄：nd.col + 1

actionText(V, from, kind, to, me, name)
  移動  → "{name} {from} → {to}"
  攻擊  → "{name} {from} 攻擊 {to}"
  爆破  → "{name} {from} 爆破 {to}"
  偵察  → "{name} {from} 偵察 {to}"
  狙擊  → "{name} {from} 狙擊 {to}"
  空降  → "{name} {from} 空降到 {to}"
  炸橋  → "{name} {from} 炸橋"
  name 省略時，開頭不寫棋名
```

- 不認得的動作種類，寫中文「未知動作」，不再露出英文。
- 放在 `record.js` 而不是 `ui.js`：測試載得到，複盤和建議也共用同一套寫法。

### 2.2 AI 建議、走棋提醒（D1）

- `moveName(m)` 改為 `LZ.actionText(V, m.from, m.mv.kind, m.mv.to, 視角, 棋名)`。
  - 視角：一般對局是 `S.human`；觀戰是 null。
  - 棋名取自 `S.board[m.from]`。這裡一定是自己的棋，不會洩漏敵方資訊。
- 用到它的三處（建議列、提醒列、走完後的提醒訊息）自動跟著改。

### 2.3 盤面建議標籤（D2）

- `ui.js` 已經會加 `sug-<種類>`，只改 CSS：
  - `.sug-move::before { content: "建議移動" }`、`.sug-attack` → 「建議攻擊」，其餘依此類推。
  - 共 7 種：移動、攻擊、爆破、偵察、狙擊、空降、炸橋。
- 炸橋的目標格標的是橋，沿用同一套樣式。

### 2.4 可爆破的格子（D3）

- `ui.js` 已經會加 `t-blast`，只補 CSS：
  - 小標籤「爆破」，和 `.t-blow` 的「炸橋」同一組樣式。
  - `cursor: pointer`。
  - 格子裡有棋時，加上和狙擊一樣的虛線框。
- 同一格同時能攻擊、爆破時，兩種標示都會出現。點下去照舊跳出動作選單。

### 2.5 複盤說明（D4、D5）

- `describe()` 的走棋步驟改用 `actionText`，視角是 `rec.human`，**不寫棋名**。
  - 理由：對局中複盤只看得到自己這方，寫敵方棋名會洩漏資訊。
  - 棋名本來就看得到：盤面上有，下面的戰報也有。
- 作弊步驟：
  - 補上 `draw`：「【作弊】和局條件改成 N 手」；N＝0 時寫「不判和」。
  - 其他作弊步驟維持原樣。

### 2.6 上一手標示（D6）

- `engine.js` 的兩處 `S.lastMove = { from, to, side }` 加上 `k: mv.kind`。
- `ui.js` 依 `lm.k` 處理：
  - 移動、攻擊、空降：照舊加 `last-from`、`last-to`。
  - 偵察、狙擊、爆破、炸橋：
    - 起點**不加** `last-from`。
    - 目標格加 `last-to` 和 `last-<種類>`。
    - CSS 用小標籤寫出動作名稱：「偵察」「狙擊」「爆破」「炸橋」。
- 舊棋譜複盤時也是現場重算，所以一樣有 `k`。
