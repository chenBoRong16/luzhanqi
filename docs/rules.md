# 原版規則

標準兩人陸軍棋，「暗棋」玩法：撞棋時只知道勝負，不知道對方是什麼棋。實體下棋時需要裁判，或由雙方互報勝負。

## 勝負

- 奪下對方**軍旗**就贏。
- 輪到自己時，沒有任何棋可以走，就輸。
- 連續 60 手都沒有攻擊，就和棋。雙方各走一步算 2 手；有人攻擊，不論勝負，就從 0 重新算。

## 盤面（每方）

- 5 欄 × 6 列。第 1 列是前線，第 6 列是大本營那一排。
- **鐵路**：第 1 列、第 5 列橫向；第 1 欄、第 5 欄的第 1～5 列縱向。
- **過河**：只能走左、中、右三條鐵路，第 2、4 欄是山，不能過。中路鐵路只接到雙方第 1 列；左、右兩路一直通到雙方第 5 列。
- **行營**（圓）：第 2 列第 2、4 欄，第 3 列第 3 欄，第 4 列第 2、4 欄。
  - 行營裡的棋不能被攻擊。
  - 行營和四周八格都有公路，可以斜走。
- **大本營**：第 6 列第 2、4 欄。走進大本營的棋，之後就不能再動。

## 棋子（每方 25 顆）

等級由大到小：司令 ＞ 軍長 ＞ 師長 ＞ 旅長 ＞ 團長 ＞ 營長 ＞ 連長 ＞ 排長 ＞ 工兵。炸彈、地雷、軍旗沒有等級，照下面的規則處理。

| 棋 | 數量 | 說明 |
| --- | --- | --- |
| 司令 | 1 | 等級最大。陣亡後，自己的軍旗位置要公開 |
| 軍長 | 1 | |
| 師長 | 2 | |
| 旅長 | 2 | |
| 團長 | 2 | |
| 營長 | 2 | |
| 連長 | 3 | |
| 排長 | 3 | |
| 工兵 | 3 | 等級最小。攻擊地雷時贏，地雷被移除。在鐵路上可以轉彎 |
| 炸彈 | 2 | 攻擊別人或被攻擊時，雙方都移除 |
| 地雷 | 3 | 不能移動 |
| 軍旗 | 1 | 不能移動。被攻擊就輸了這盤 |

## 佈陣

- 軍旗放在大本營。
- 地雷只能放最後兩列。
- 炸彈不能放第 1 列。
- 行營開局必須空著。25 顆剛好放滿其他 25 格。

## 移動

每一手移動自己的一顆棋。

- **公路**：走 1 格，包括行營的斜線。
- **鐵路**：沿同一條鐵路直線走，格數不限。
  - 路上遇到第一顆棋就要停住，不能跳過去。
  - 那顆是敵棋，可以攻擊它；是自己的棋，就只能停在它前面。
  - 工兵可以在鐵路的交叉口轉彎，其他棋只能走直線。
- **攻擊**：走到敵棋所在的格子就是攻擊。行營裡的敵棋不能攻擊。

## 攻擊的結果（依序判斷）

1. 被攻擊的是軍旗：攻擊方贏得這盤。
2. 任一方是炸彈：雙方都移除。
3. 被攻擊的是地雷：
   - 攻擊方是工兵：地雷移除，工兵移到那一格。
   - 其他棋：攻擊方移除，地雷留著。
4. 等級相同：雙方都移除。
5. 等級不同：
   - 攻擊方較大：被攻擊的棋移除，攻擊方移到那一格。
   - 攻擊方較小：攻擊方移除。
