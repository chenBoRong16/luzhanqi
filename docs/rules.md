# 原版規則

標準兩人陸軍棋（有裁判的「暗棋」玩法：只知道勝負，不知道對方是什麼棋）。

## 勝負

- 奪下對方**軍旗**即勝。
- 輪到的一方沒有棋可以動，判負。
- 連續 60 手沒有對撞，判和。

## 盤面（每方）

- 5 欄 × 6 列。第 1 列是前線，第 6 列是大本營那一排。
- **鐵路**：第 1 列、第 5 列橫向；第 1 欄、第 5 欄的第 1～5 列縱向。
- **過河**：只有左、中、右三條鐵路，第 2、4 欄是山。中路鐵路只連接雙方前線；左、右兩路一路通到雙方第 5 列。
- **行營**（圓）：第 2 列第 2、4 欄，第 3 列第 3 欄，第 4 列第 2、4 欄。行營裡的棋不能被攻擊；行營和四周八格都有公路相連（可斜走）。
- **大本營**：第 6 列第 2、4 欄。進了大本營的棋不能再動。

## 棋子（每方 25 顆）

| 棋 | 數量 | 說明 |
| --- | --- | --- |
| 司令 | 1 | 最大；陣亡後必須亮出軍旗位置 |
| 軍長 | 1 | |
| 師長 | 2 | |
| 旅長 | 2 | |
| 團長 | 2 | |
| 營長 | 2 | |
| 連長 | 3 | |
| 排長 | 3 | |
| 工兵 | 3 | 最小，唯一能排雷；鐵路上可以轉彎 |
| 炸彈 | 2 | 撞到誰都同歸於盡 |
| 地雷 | 3 | 不能動；除了工兵，撞上的棋陣亡、雷留著 |
| 軍旗 | 1 | 不能動；被奪即敗 |

## 佈陣限制

- 軍旗：大本營
- 地雷：最後兩列
- 炸彈：不能放第一列
- 行營：開局必須空著（25 顆剛好放滿其他 25 格）

## 移動

- 公路：一次一格（含行營的斜線）。
- 鐵路：沿同一條鐵路直線走任意格，中間不能有棋；工兵可以在鐵路網上轉彎。
- 遇到對方的棋可以攻擊，但行營裡的不行；鐵路上不能穿過任何棋。

## 對撞（依序判斷）

1. 對方是軍旗：奪旗獲勝
2. 任一方是炸彈：同歸於盡
3. 對方是地雷：工兵勝（排雷），其他棋陣亡
4. 同級：同歸於盡
5. 大吃小
