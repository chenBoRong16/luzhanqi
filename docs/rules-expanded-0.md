# 擴充版-0 規則

和原版相比：地圖加寬、加了新棋子和新地形，但**規則保持簡單**：棋的強弱只看固定等級，或固定的「誰剋誰」，不會因為地形或動作而改變。所有狀態都能放在實體棋盤上。

沒寫到的部分都和原版一樣（見 `rules.md`）。每條擴充規則都可以在遊戲的「規則開關」裡單獨關掉；以下是全開（預設）時的規則。

## 勝負

- 奪下對方軍旗即勝。
- 輪到的一方沒有棋可以動，判負；但如果只是棋全部翻倒，就跳過這一回合。
- 連續 80 手沒有對撞，判和（看盤邊的計數軌）。

## 盤面（每方 7 欄 × 7 列；欄、列從 1 起算，第 1 列是前線）

```
       1    2    3    4    5    6    7
第1列  ═══  ═══  ═══  ═══  ═══  ═══  ═══    前線鐵路
第2列  ║   (營)  ·    ║    ·   (營)  ║
第3列  ║    ·   (營)  ║   (營)  ·    ║
第4列  ║   (營) {林}  ║   {林} (營)  ║     {林}＝森林
第5列  ║    ·   (營)  ║   (營)  ·    ║
第6列  ═══  ═══  ═══  ═══  ═══  ═══  ═══    後方鐵路
第7列  ·    ·   [本]   ·   [本]  ·    ·      [本]＝大本營
```

- **過河口五個**：第 1、4、7 欄是鐵路（第 4 欄的中路一路貫穿到雙方後方鐵路）；第 2、6 欄是**公路橋**；第 3、5 欄是山。
- **行營** 8 個；**大本營** 2 個。
- **森林**（第 3、5 欄的第 4 列）：
  - 走到森林的棋**翻倒**，下一回合不能動。
  - 森林裡的棋不能被偵察、也不會被雷達揭露。
- **可炸毀的橋**：
  - 炸彈站在橋頭（第 2 或第 6 欄的第 1 列）時，可以用一回合**炸橋**。
  - 炸彈消失，該橋永久斷掉。

## 棋子（每方 35 顆）

| 棋 | 數量 | 能力 |
| --- | --- | --- |
| 司令 | 1 | 最大；陣亡後軍旗翻成明棋 |
| 軍長 | 1 | |
| **坦克** | 2 | 和一般棋一樣走 1 格、攻擊相鄰的棋；另外可以沿公路連走 2 格，途中可以轉一次彎，第 2 格可以是空格或敵棋（攻擊）。第 1 格有棋（不論敵我），或是沼澤、森林時，就不能連走 2 格，只能照一般棋走。攻擊地雷時勝 |
| 師長、旅長、團長、營長 | 各 2 | |
| **防空炮** | 1 | 等級介於營長和連長之間。公路相鄰的格子，對方不能空降進來。被傘兵攻擊必勝 |
| 連長、排長 | 各 2 | |
| **傘兵** | 2 | 每顆一生一次空降，跳到對方前三列的空格（行營、大本營除外）；空降不能攻擊。落地後翻成明棋並翻倒，下一回合不能動 |
| **偵察** | 2 | 用一回合偵察公路距離 2 以內的一顆敵棋（行營裡的也可以，中間隔著棋也行）。被偵察的棋和偵察自己都翻成明棋 |
| 工兵 | 4 | 排雷；鐵路上可以轉彎 |
| **間諜** | 1 | 最弱；但主動攻擊司令時勝 |
| **雷達站** | 1 | 不能動，不能放第一列。敵棋走到它公路相鄰的格子時翻成明棋。被任何棋攻擊都會被移除（炸彈仍同歸於盡） |
| 炸彈 | 3 | 撞到誰都同歸於盡 |
| 地雷 | 4 | 不能動；工兵或坦克可以排掉 |
| 軍旗 | 1 | |

等級：司令 ＞ 軍長 ＞ 坦克 ＞ 師長 ＞ 旅長 ＞ 團長 ＞ 營長 ＞ 防空炮 ＞ 連長 ＞ 排長 ＞ 傘兵 ＞ 偵察 ＞ 工兵 ＞ 間諜

## 佈陣

- 軍旗在大本營；地雷只放最後兩列；炸彈、雷達站不放第一列；行營開局必須空著。
- 地圖上有其他地形時：高山不能放棋；沼澤不能放坦克、地雷、軍旗、雷達站。
- 41 格放 35 顆，有 6 格空格；佈陣時可以把棋移到空格。

## 地形（出現在哪裡由地圖決定）

可以在對局頁的「地圖」卡片換地圖，或用**地圖編輯器**自己畫。每條規則都只看格子種類和步數，不需要新配件。

| 地形 | 規則 | 現實理由 |
| --- | --- | --- |
| 沼澤（波浪紋） | 走到這格的棋翻倒一回合。坦克不能進入、攻擊或穿過。不能空降，不能鋪鐵路 | 坦克太重會陷住；泥地無法著陸、鋪軌 |
| 平原（點狀紋） | 坦克可以連走 3 格，途中最多轉一次彎，第 3 格可以是空格或敵棋（攻擊）。出發格和這 3 格都要是平原；前 2 格有棋（不論敵我）時，就不能連走 3 格。目標站在平原上時，偵察距離多 1 格、雷達範圍 2 格 | 開闊地適合裝甲推進，但也無處躲藏 |
| 村莊（小房子） | 裡面的棋不能被偵察、雷達、狙擊。不能空降。從村莊出發的棋只能走公路一格 | 建築遮蔽視線，巷弄出不快 |
| 高山（山形） | 不能進入 | 天然屏障 |
| 標準軌 | 和原本的鐵路一樣 | 大多數國家的幹線 |
| 寬軌（雙線） | 和標準軌一樣，只是軌距不同 | 部分國家用寬軌，跨國要換軌 |
| 窄軌（細線、密枕木） | 一次最多走 3 格，可以順著彎道走。坦克不能上 | 窄軌載重小、彎道多 |
| 換軌站（菱形框） | 兩種軌距相接的格子。沿鐵路走到這裡必須停下，工兵也一樣；下一手才能換另一種軌距 | 軌距不同，車廂過不去，要換車或換轉向架 |

另外，地圖可以拆掉部分公路（偏遠地區路網稀疏），每一欄的過河口可以是鐵路、公路橋或山。

**內建範例地圖**：標準、兩國換軌、偏遠平原、沼澤森林、山地。

## 實體棋盤玩法

| 狀態 | 怎麼放 |
| --- | --- |
| 明棋（偵察、雷達、空降、司令陣亡亮旗） | 棋子正面朝上，之後一直公開 |
| 翻倒（走到森林或沼澤、空降落地） | 棋子橫放，到該方下一回合結束時扶正 |
| 傘兵已空降 | 棋子旁放「已空降」小標記 |
| 斷橋 | 橋上放「斷橋」標記 |
| 判和計數 | 盤邊 0～80 計數軌上的指示物；發生對撞就歸零 |

**配件清單（每局）**：棋盤 1 張（含計數軌）、紅藍棋子各 35 顆、「已空降」標記 4 個、「斷橋」標記 2 個、計數指示物 1 個。對撞判定和原版一樣需要裁判，或由雙方互報。
