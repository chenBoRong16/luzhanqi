# 擴充版-0 規則

和原版相比：地圖加寬，加了新棋子和新地形。棋的強弱只看固定的等級，或固定的「誰剋誰」，不會因為地形改變。所有狀態都能放在實體棋盤上。

這裡沒寫到的，都和原版一樣（見 `rules.md`）。每條新規則都可以在遊戲的「規則開關」裡單獨關掉；下面寫的是全部打開（預設）時的規則。

## 勝負

- 奪下對方**軍旗**就贏。
- 輪到自己時，沒有任何棋可以走，就輸。例外：如果是因為棋全部翻倒（見下方「翻倒」）而不能走，就跳過這一回合，不算輸。
- 連續 80 手都沒有棋被吃掉，就和棋。
  - 雙方各走一步算 2 手。
  - 攻擊（不論勝負）或狙擊命中，就從 0 重新算；移動、偵察、空降、炸橋、狙擊失敗都會加 1。
  - 手數可以在「設置」裡改，也可以關掉，不判和。

## 盤面（標準地圖：每方 7 欄 × 7 列；欄、列從 1 起算，第 1 列是前線）

```
       1    2    3    4    5    6    7
第1列  ═══  ═══  ═══  ═══  ═══  ═══  ═══    前線鐵路
第2列  ║   (營)  ·    ║    ·   (營)  ║
第3列  ║    ·   (營)  ║   (營)  ·    ║
第4列  ║   (營) {林}  ║   {林} (營)  ║     {林}＝森林
第5列  ║    ·   (營)  ║   (營)  ·    ║
第6列  ═══  ═══  ═══  ═══  ═══  ═══  ═══    後方鐵路
第7列  ·    ·   [本]   ·   [本]  ·    ·      [本]＝大本營
```

- **過河口**：第 1、4、7 欄是鐵路，第 4 欄的中路一直通到雙方的後方鐵路；第 2、6 欄是**公路橋**；第 3、5 欄是山，不能過。
- **行營** 8 個，**大本營** 2 個，規則和原版一樣。
- **森林**：第 3、5 欄的第 4 列。規則見「地形」。
- **炸橋**：
  - 炸彈站在任一方的橋頭（公路橋那一欄的第 1 列）時，可以用一手**炸橋**。
  - 炸彈移除，這座橋永久斷掉，這一欄從此不能過河。

## 翻倒

- 棋子會在三種情況翻倒：走到森林、走到沼澤、傘兵空降落地。
- 翻倒的棋，在它主人的下一回合不能動，也不能偵察、狙擊、炸橋。那一回合結束時，它就扶正。
- 翻倒的棋照樣可以被攻擊，等級不變。

## 棋子（每方 35 顆）

等級由大到小：司令 ＞ 軍長 ＞ 坦克 ＞ 師長 ＞ 旅長 ＞ 團長 ＞ 營長 ＞ 防空炮 ＞ 連長 ＞ 排長 ＞ 傘兵 ＞ 偵察 ＞ 工兵 ＞ 間諜。雷達站、炸彈、地雷、軍旗沒有等級，照下表的規則處理。

| 棋 | 數量 | 能力 |
| --- | --- | --- |
| 司令 | 1 | 等級最大。陣亡後，自己的軍旗翻成明棋 |
| 軍長 | 1 | |
| **坦克** | 2 | 和一般棋一樣走 1 格、攻擊相鄰的棋。另外可以沿公路連走 2 格，途中可以轉一次彎，第 2 格可以是空格或敵棋（攻擊）。第 1 格有棋（不論敵我），或是沼澤、森林時，就不能連走 2 格，只能照一般棋走。攻擊地雷時贏，地雷移除 |
| 師長、旅長、團長、營長 | 各 2 | |
| **防空炮** | 1 | 和防空炮公路相鄰的格子，對方不能空降進來。被傘兵攻擊時一定贏 |
| 連長、排長 | 各 2 | |
| **傘兵** | 2 | 每顆一盤只能**空降**一次：用一手從任何位置跳到對方前 3 列的空格。不能跳進行營、大本營、高山、沼澤、村莊，也不能跳到對方防空炮公路相鄰的格子。空降不能同時攻擊。落地後翻成明棋，並且翻倒 |
| **偵察** | 2 | 用一手**偵察**一顆敵棋：從偵察沿公路數 2 步以內，不管路上有沒有棋。行營裡的可以偵察；森林、村莊裡的不行；已經確定是什麼的棋不能再偵察。偵察後，被偵察的棋和偵察自己都翻成明棋 |
| 工兵 | 4 | 攻擊地雷時贏，地雷移除。在鐵路上可以轉彎 |
| **間諜** | 1 | 等級最小。主動攻擊司令時贏；被司令攻擊時照樣輸 |
| **雷達站** | 1 | 不能移動，不能放第 1 列。每一手結束時，和雷達站公路相鄰的敵棋都翻成明棋（森林、村莊裡的除外）。被任何棋攻擊時雷達站移除，攻擊方移到那一格；炸彈攻擊時雙方都移除 |
| 炸彈 | 3 | 攻擊別人或被攻擊時，雙方都移除 |
| 地雷 | 4 | 不能移動。工兵、坦克攻擊時地雷移除；炸彈攻擊時雙方都移除；其他棋攻擊時攻擊方移除，地雷留著 |
| 軍旗 | 1 | 不能移動。被攻擊就輸了這盤 |

**明棋**：雙方都知道是什麼的棋，之後一直公開，實體棋盤上正面朝上。

## 佈陣

- 軍旗放在大本營；地雷只能放最後兩列；炸彈、雷達站不能放第 1 列；行營開局必須空著。
- 地圖上有其他地形時：高山不能放棋；沼澤不能放坦克、地雷、軍旗、雷達站。
- 標準地圖 41 格放 35 顆，有 6 格空格。佈陣時可以把棋移到空格。

## 地形

地形出現在哪裡由地圖決定。可以在對局頁的「地圖」卡片換地圖，或用**地圖編輯器**自己畫。

| 地形 | 規則 | 現實理由 |
| --- | --- | --- |
| 森林（樹） | 走到森林的棋翻倒。森林裡的棋不能被偵察，雷達也看不到 | 樹林好藏身，但難走 |
| 沼澤（波浪紋） | 走到沼澤的棋翻倒。坦克不能進入，不能攻擊沼澤裡的棋，連走時也不能經過沼澤。不能空降進來，不能鋪鐵路 | 坦克太重會陷住；泥地無法著陸、鋪軌 |
| 平原（點狀紋） | 坦克可以連走 3 格，途中最多轉一次彎，第 3 格可以是空格或敵棋（攻擊）。出發格和這 3 格都要是平原；前 2 格有棋（不論敵我）時，就不能連走 3 格。另外，敵棋站在平原上時，偵察從 3 步遠就能偵察它，雷達在 2 步內就能看到它 | 開闊地適合裝甲推進，但也無處躲藏 |
| 村莊（小房子） | 村莊裡的棋不能被偵察，雷達也看不到。不能空降進來。從村莊出發的棋，這一手只能沿公路走 1 格：不能走鐵路，坦克不能連走，傘兵不能空降 | 建築遮蔽視線，巷弄出不快 |
| 高山（山形） | 不能進入 | 天然屏障 |
| 標準軌 | 和原版的鐵路一樣 | 大多數國家的幹線 |
| 寬軌（雙線） | 和標準軌一樣，只是軌距不同 | 部分國家用寬軌，跨國要換軌 |
| 窄軌（細線、密枕木） | 一手最多走 3 格，工兵也一樣。在窄軌上任何棋都可以順著軌道轉彎；標準軌、寬軌上只有工兵能轉彎。坦克不能走窄軌。路上遇到棋的規則和一般鐵路一樣 | 窄軌載重小、彎道多 |
| 換軌站（菱形框） | 兩種軌距相接的格子。沿鐵路走到這裡就要停下，工兵也一樣；下一手才能從這裡走另一種軌距 | 軌距不同，車廂過不去，要換車 |

地圖也可以拆掉部分公路；每一欄的過河口可以是鐵路、公路橋或山。地圖至少要有一條鐵路過河，因為公路橋可能全被炸斷。

**內建範例地圖**：標準、兩國換軌、偏遠平原、沼澤森林、山地。

## 實體棋盤玩法

| 狀態 | 怎麼放 |
| --- | --- |
| 明棋 | 棋子正面朝上，之後一直公開 |
| 翻倒 | 棋子橫放；主人的下一回合結束時扶正 |
| 傘兵已空降 | 棋子旁放「已空降」小標記 |
| 斷橋 | 橋上放「斷橋」標記 |
| 判和計數 | 盤邊 0～80 計數軌上的指示物：每一手加 1，攻擊或狙擊命中就歸零 |

**配件清單（每局）**：棋盤 1 張（含計數軌）、紅藍棋子各 35 顆、「已空降」標記 4 個、「斷橋」標記 2 個、計數指示物 1 個。攻擊的勝負和原版一樣需要裁判，或由雙方互報。
