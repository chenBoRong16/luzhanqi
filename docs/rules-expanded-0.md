# 擴充版-0 規則

和原版相比：地圖加寬，加了新棋子和新地形。棋的強弱只看固定的等級，不會因為地形改變。所有狀態都能放在實體棋盤上。

規則分成六個部分：**移動、攻擊、視線、防護、翻倒、開局**。每條規則只寫一次。地形只寫它屬於哪幾個部分，細節回到那個部分去看。

這裡沒寫到的，都和原版一樣（見 `rules.md`）。每條新規則都可以在遊戲的「規則開關」裡單獨關掉；下面寫的是全部打開（預設）時的規則。

## 勝負

- 奪下對方**軍旗**就贏。
- 輪到自己時沒有任何棋可以走，就輸。例外：棋全部翻倒而不能走時，跳過這一回合，不算輸。
- 連續 80 手都沒有棋被吃掉，就和棋。
  - 雙方各走一步算 2 手。
  - 攻擊（不論勝負）、狙擊命中、傘兵被擊落時歸零；其他動作都加 1。
  - 手數可以在「設置」裡改，也可以關掉，不判和。

## 盤面（標準地圖：每方 7 欄 × 7 列；欄、列從 1 起算，第 1 列是前線）

```
       1     2     3     4     5     6     7
第1列  ═══  [堡]  ═══   ═══   ═══  [堡]  ═══    前線鐵路；[堡]＝碉堡
第2列  ║    (營)  {林}   ║    <原>  (營)  ║
第3列  ║    {林}  (營)   ║    (營)  <原>  ║
第4列  ║    (營)  {林}   ║    <原>  (營)  ║
第5列  ║     ·    (營)   ║    (營)  [村]  ║
第6列  ═══  ═══   ═══   ═══   ═══  ═══   ═══    後方鐵路
第7列   ·    ·    [本]   ·    [本]   ·    ·      [本]＝大本營
```

- **過河口**：第 1、4、7 欄是鐵路，第 4 欄的中路一直通到雙方的後方鐵路；第 2、6 欄是**公路橋**，橋頭是碉堡；第 3、5 欄是山，不能過。
- **三條路線**：
  - 左路是森林帶：好藏，但走進去會翻倒。
  - 右路是平原帶：坦克好衝，但容易被看到。
  - 中路是鐵路：最快，但完全暴露。
- 其他地圖可以在對局頁的「地圖」卡片換，或用**地圖編輯器**自己畫。

## 1. 移動

每一手移動自己的一顆棋，或做一個特殊動作（偵察、空降、爆破、炸橋）。

- **公路**：走 1 格。行營和四周八格都有公路，可以斜走。
- **鐵路**：
  - 沿同一條鐵路直線走，格數不限。
  - 路上遇到第一顆棋就停：是敵棋可以攻擊它，是自己的棋就停在它前面。
  - 工兵可以在鐵路的交叉口轉彎。
- **軌距**：
  - 標準軌、寬軌：照上面的鐵路規則。
  - **窄軌**：一手最多走 3 格；任何棋都可以順著窄軌轉彎；坦克不能走窄軌。
  - **換軌站**（兩種軌距相接的格子）：沿鐵路走到這裡就停，工兵也一樣。
- **坦克衝刺**：
  - 坦克可以沿公路連走 2 格，可以轉一次彎；整段都在平原上時，最多 3 格。
  - 經過的格子要空，而且不能是沼澤、森林。最後一格可以是敵棋（攻擊）。
  - 不衝刺時，照一般棋走 1 格。
- **空降**：
  - 每顆傘兵一盤一次，用一手從任何位置跳到對方前 3 列的空格。
  - 落點只能是一般格或平原。
  - 落點在對方防空炮**看得到**的地方（見「3. 視線」，距離 1）時，傘兵被**擊落**（移除），防空炮翻成明棋。這算有棋被吃掉，判和計數歸零。
    - 落點是平原時，距離 2 也會被擊落（平原暴露）。
  - 沒被擊落：落地後翻成明棋，並且翻倒。空降時不能攻擊。
- **從村莊出發**：這一手只能沿公路走 1 格，不能走鐵路、衝刺、空降。
- **大本營**：
  - 任何棋都可以走出大本營（軍旗、地雷本來就不能動）。
  - 走進**對方**大本營的棋翻成明棋。
- **不能進入**：高山；坦克太重，不能進入沼澤。
- **炸橋**：炸彈站在任一方的橋頭時，可以用一手炸橋。炸彈移除，這座橋永久斷掉，這一欄從此不能過河。

## 2. 攻擊

走到敵棋所在的格子就是攻擊。防護格裡的棋不能攻擊（見「4. 防護」）。

**等級**（由大到小）：

司令 ＞ 軍長＝坦克 ＞ 師長 ＞ 旅長 ＞ 團長 ＞ 營長 ＞ 連長＝防空炮 ＞ 排長＝傘兵 ＞ 工兵＝偵察 ＞ 間諜 ＞ 雷達站

炸彈、地雷、軍旗沒有等級。

**結果**（依序判斷）：

1. 被攻擊的是軍旗：攻擊方贏得這盤。
2. 任一方是炸彈：雙方都移除。
3. 被攻擊的是地雷：
   - 工兵攻擊：地雷移除，工兵移過去。
   - 其他棋攻擊（含坦克）：攻擊方移除，地雷留著。
4. 間諜主動攻擊司令：間諜贏。
5. 其餘比等級：
   - 攻擊方較大：被攻擊的棋移除，攻擊方移過去。
   - 攻擊方較小：攻擊方移除。
   - 同級：雙方都移除。

司令陣亡時，自己的軍旗翻成明棋。

## 3. 視線

- **看得到**：沿公路數到目標的步數在距離以內，不管路上有沒有棋；而且目標不在**隱蔽**格（森林、村莊）。
- **暴露**：目標站在**平原**上時，距離多 1。
- **偵察**：
  - 用一手偵察一顆看得到的敵棋，距離 2。
  - 已經確定是什麼的棋不能再偵察。
  - 偵察後，被偵察的棋和偵察自己都翻成明棋。
- **雷達站**：每一手結束時，看得到的敵棋都翻成明棋，距離 1。
- **防空炮**：看得到落點，就擊落傘兵，距離 1（見「1. 移動」的空降）。

**明棋**：雙方都知道是什麼的棋，之後一直公開；實體棋盤上正面朝上。

## 4. 防護

- **防護格**：行營、碉堡。防護格裡的棋**不能被攻擊**，炸彈、坦克也不行。
- **爆破**：
  - **工兵**可以用一手爆破防護格。
  - 哪一方半場的都可以，空的也可以，只要裡面**沒有自己的棋**。所以工兵不能炸自己站的格子；敵棋躲進我方半場的行營，也炸得開。
  - 工兵**站在原地爆破，不用走進去**，但只能炸**相鄰**的格子：
    - 公路相鄰的一格，行營可以走斜線。
    - 鐵路上相鄰的一格。
    - 要炸遠處的，得先走過去：炸藥要貼到工事上。
  - 結果：
    - 這格永久失去防護，變成一般格，公路照舊。
    - 工兵留在原地，翻成明棋。
    - 裡面的棋不動、不受傷。要打它，下一手再攻擊。這時這格已經沒有防護，照一般規則比大小。
  - 點防護格時：
    - 裡面有對方的棋：只能爆破（防護格裡的棋打不到）。
    - 空的：可以選「移動」走進去，或選「爆破」。
- **行營和碉堡的差別**：

| | 行營 | 碉堡 |
|---|---|---|
| 開局 | 必須空著 | 可以放棋 |
| 公路 | 和四周八格相連，可以斜走 | 一般格的公路 |
| 位置 | 沿進攻路線，當中繼站 | 要道，例如公路橋的橋頭 |

碉堡在橋頭，炸彈站在碉堡上照樣可以炸橋；橋斷了，碉堡還在。

## 5. 翻倒

- 會翻倒的情況：走到森林、走到沼澤、傘兵空降落地。
- 翻倒的棋在它主人的下一回合不能做任何動作；那一回合結束時扶正。
- 翻倒的棋照樣可以被攻擊，等級不變。

## 6. 開局

- 不能放棋的格子：行營、沼澤、高山。
- 軍旗放在大本營；地雷只能放最後兩列；炸彈、雷達站不能放第 1 列。
- 標準地圖 41 格放 35 顆，有 6 格空格；佈陣時可以把棋移到空格。

## 地形一覽

| 地形 | 屬於 | 摘要 | 現實理由 |
|---|---|---|---|
| 行營（圓） | 防護、開局 | 打不到，工兵可爆破；開局空著；可斜走 | 營地有壕溝 |
| 碉堡（城垛方框） | 防護 | 打不到，工兵可爆破；開局可放棋 | 混凝土工事 |
| 森林（樹） | 視線、翻倒、移動 | 隱蔽；走進去翻倒；坦克衝刺不能經過 | 樹林好藏，但難走 |
| 村莊（小房子） | 視線、移動 | 隱蔽；出發只能沿公路走 1 格；不能空降 | 建築遮蔽，巷弄狹窄 |
| 平原（點狀紋） | 視線、移動 | 暴露；坦克衝刺多 1 格 | 開闊地 |
| 沼澤（波浪紋） | 翻倒、移動、開局 | 走進去翻倒；坦克進不去；不能空降；開局不能放棋；不能鋪鐵路 | 泥地陷人 |
| 高山（山形） | 移動、開局 | 不能進入，不能放棋 | 天然屏障 |
| 窄軌（細線、密枕木） | 移動 | 一手最多 3 格，能順著軌道轉彎，坦克不能走 | 載重小、彎道多 |
| 寬軌（雙線） | 移動 | 和標準軌一樣，只是軌距不同 | 跨國要換軌 |
| 換軌站（菱形框） | 移動 | 沿鐵路走到這裡就停 | 車廂過不去 |

**內建範例地圖**：標準、兩國換軌、偏遠平原、沼澤森林、山地。地圖至少要有一條鐵路過河，因為公路橋可能全被炸斷。

## 實體棋盤玩法

| 狀態 | 怎麼放 |
|---|---|
| 明棋 | 棋子正面朝上，之後一直公開 |
| 翻倒 | 棋子橫放；主人的下一回合結束時扶正 |
| 傘兵已空降 | 棋子旁放「已空降」小標記 |
| 斷橋 | 橋上放「斷橋」標記 |
| 已炸毀的防護格 | 格子上放「已炸毀」標記 |
| 判和計數 | 盤邊 0～80 計數軌上的指示物：每一手加 1，攻擊或狙擊命中就歸零 |

**配件清單（每局）**：
- 棋盤 1 張（含計數軌）
- 紅藍棋子各 35 顆
- 「已空降」標記 4 個
- 「斷橋」標記 2 個
- 「已炸毀」標記 10 個
- 計數指示物 1 個

攻擊的勝負和原版一樣需要裁判，或由雙方互報。

## 附錄：例外與理由

下面是不照一般規則的地方，每條都有一句理由。

| 例外 | 理由 |
|---|---|
| 炸彈撞誰都同歸於盡 | 一爆連自己一起炸掉 |
| 只有工兵能排雷 | 地雷是一片雷區，要專業工兵才清得掉 |
| 間諜主動攻擊司令時贏 | 刺客專殺指揮官 |
| 司令陣亡，軍旗翻成明棋 | 指揮崩潰，司令部的位置跟著暴露 |
| 工兵能在鐵路上轉彎 | 工兵就是鐵道兵，熟悉路網 |
| 窄軌上任何棋都能順著軌道轉彎 | 火車順著軌道走，窄軌彎道多 |
| 坦克能衝刺；不能進沼澤、不能走窄軌，衝刺不能經過森林 | 裝甲跑得快，但太重，樹林也擋路 |
| 換軌站要停 | 軌距不同，車廂過不去 |
| 防護格只有工兵能爆破 | 工事擋得住衝鋒，要靠工兵爆破 |
| 爆破只能炸相鄰的格子 | 炸藥要貼到工事上 |
| 行營開局要空，碉堡可以放棋 | 行營是進攻途中的中繼營地，開戰後才進駐；碉堡是平時就有守軍的工事 |
| 雷達站不能移動 | 雷達是固定設備，不是部隊 |
| 森林、沼澤會翻倒 | 難走，要停下來重整 |
| 森林、村莊看不到；平原容易被看到 | 有沒有遮蔽 |
| 從村莊出發只能沿公路走 1 格 | 巷弄狹窄，出不快 |
| 偵察時自己也曝光 | 偵察兵靠近了，對方也看見他 |
| 傘兵落在防空炮看得到的地方會被擊落，防空炮翻成明棋 | 降落傘被防空陣地看到就會被打下來；開火也暴露了陣地位置 |
| 傘兵只能跳到對方前 3 列 | 空降部隊要在己方火力支援範圍內；遊戲上也避免直接空降到大本營旁 |
| 走進對方大本營翻成明棋 | 攻進指揮部，行蹤一定曝光 |
| 地雷只放最後兩列、炸彈不放第 1 列 | 地雷是守大本營的最後一道防線；炸彈要藏在後方，放在第一線會先被識破 |
