# 擴充版-0 規則

和原版相比：地圖加寬、加了新棋子和新地形，但**規則保持簡單**：棋的強弱只看固定等級，或固定的「誰剋誰」，不會因為地形或動作而改變。所有狀態都能放在實體棋盤上。

沒寫到的部分都和原版一樣（見 `rules.md`）。每條擴充規則都可以在遊戲的「規則開關」裡單獨關掉；以下是全開（預設）時的規則。

## 勝負

- 奪下對方軍旗即勝。
- 輪到的一方沒有棋可以動，判負；但如果只是棋全部翻倒，就跳過這一回合。
- 連續 80 手沒有對撞，判和（看盤邊的計數軌）。

## 盤面（每方 7 欄 × 7 列；欄、列從 1 起算，第 1 列是前線）

```
       1    2    3    4    5    6    7
第1列  ═══  ═══  ═══  ═══  ═══  ═══  ═══    前線鐵路
第2列  ║   (營)  ·    ║    ·   (營)  ║
第3列  ║    ·   (營)  ║   (營)  ·    ║
第4列  ║   (營) {林}  ║   {林} (營)  ║     {林}＝森林
第5列  ║    ·   (營)  ║   (營)  ·    ║
第6列  ═══  ═══  ═══  ═══  ═══  ═══  ═══    後方鐵路
第7列  ·    ·   [本]   ·   [本]  ·    ·      [本]＝大本營
```

- **過河口五個**：第 1、4、7 欄是鐵路（第 4 欄的中路一路貫穿到雙方後方鐵路）；第 2、6 欄是**公路橋**；第 3、5 欄是山。
- **行營** 8 個；**大本營** 2 個。
- **森林**（第 3、5 欄的第 4 列）：
  - 走進森林的棋**翻倒**，下一回合不能動。
  - 森林裡的棋不能被偵察、也不會被雷達揭露。
- **可炸毀的橋**：
  - 炸彈站在橋頭（第 2 或第 6 欄的第 1 列）時，可以用一回合**炸橋**。
  - 炸彈消失，該橋永久斷掉。

## 棋子（每方 35 顆）

| 棋 | 數量 | 能力 |
| --- | --- | --- |
| 司令 | 1 | 最大；陣亡後軍旗翻成明棋 |
| 軍長 | 1 | |
| **坦克** | 2 | 公路上一次走兩格，可以轉一次彎；中間那格要空，只能在第二格攻擊。攻擊地雷時勝 |
| 師長、旅長、團長、營長 | 各 2 | |
| **防空炮** | 1 | 等級介於營長和連長之間。公路相鄰的格子，對方不能空降進來。被傘兵攻擊必勝 |
| 連長、排長 | 各 2 | |
| **傘兵** | 2 | 每顆一生一次空降，跳到對方前三列的空格（行營、大本營除外）；空降不能攻擊。落地後翻成明棋並翻倒，下一回合不能動 |
| **偵察** | 2 | 用一回合偵察公路距離 2 以內的一顆敵棋（行營裡的也可以，中間隔著棋也行）。被偵察的棋和偵察自己都翻成明棋 |
| 工兵 | 4 | 排雷；鐵路上可以轉彎 |
| **間諜** | 1 | 最弱；但主動攻擊司令時勝 |
| **雷達站** | 1 | 不能動，不能放第一列。敵棋走到它公路相鄰的格子時翻成明棋。被任何棋攻擊都會被移除（炸彈仍同歸於盡） |
| 炸彈 | 3 | 撞到誰都同歸於盡 |
| 地雷 | 4 | 不能動；工兵或坦克可以排掉 |
| 軍旗 | 1 | |

等級：司令 ＞ 軍長 ＞ 坦克 ＞ 師長 ＞ 旅長 ＞ 團長 ＞ 營長 ＞ 防空炮 ＞ 連長 ＞ 排長 ＞ 傘兵 ＞ 偵察 ＞ 工兵 ＞ 間諜

## 佈陣

- 軍旗在大本營；地雷只放最後兩列；炸彈、雷達站不放第一列；行營開局必須空著。
- 41 格放 35 顆，有 6 格空格；佈陣時可以把棋移到空格。

## 實體棋盤玩法

| 狀態 | 怎麼放 |
| --- | --- |
| 明棋（偵察、雷達、空降、司令陣亡亮旗） | 棋子正面朝上，之後一直公開 |
| 翻倒（走進森林、空降落地） | 棋子橫放，到該方下一回合結束時扶正 |
| 傘兵已空降 | 棋子旁放「已空降」小標記 |
| 斷橋 | 橋上放「斷橋」標記 |
| 判和計數 | 盤邊 0～80 計數軌上的指示物；發生對撞就歸零 |

**配件清單（每局）**：棋盤 1 張（含計數軌）、紅藍棋子各 35 顆、「已空降」標記 4 個、「斷橋」標記 2 個、計數指示物 1 個。對撞判定和原版一樣需要裁判，或由雙方互報。
