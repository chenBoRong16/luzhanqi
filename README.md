## 三個版本

| 版本 | 內容 |
| --- | --- |
| `原版/` | 標準兩人陸軍棋：每方 5×6、25 顆 |
| `擴充版-0/` | 每方 7×7、35 顆、五個過河口。新棋：坦克、傘兵、偵察、間諜、防空炮、雷達站。新地形：森林、可炸毀的橋。**規則保持簡單**，沒有「等效等級」類規則 |
| `擴充版-1/` | 擴充版-0 的全部，再加碉堡（站上去防守高一級）、狙擊手（以營長等級狙擊兩格外的敵棋）。每方 36 顆 |

兩個擴充版都可以換地圖，或用 `地圖編輯器/` 自己畫（軌距、平原、村莊、森林、沼澤、高山）。

兩個擴充版都能做成實體棋盤遊戲：所有狀態都在盤面上（明棋、翻倒、已空降標記、斷橋標記、判和計數軌），沒有任何數值計算。規則全文和實體配件清單在 `docs/`。

## 功能（三版都有）

**標記敵棋**
- 點敵棋或按右鍵，選你猜的棋種。依推理不可能的棋種會畫刪除線，但仍然可以選。
- 「自動推測」會依對撞結果與移動方式，在敵棋右下角用小字寫出範圍，例如「旅↑」代表旅長以上。
- 金框＝明棋（雙方都看得到）；橫倒的棋＝翻倒（下一回合不能動）；自己的棋右上角有紅點＝對方已推得它是什麼。

**佈局檔匯入匯出**
- 佈陣時按「匯出佈局」可以下載 `.json` 或複製文字；按「匯入佈局」可以選檔或貼上文字。
- 對戰中按匯出，匯出的是這盤的**開局**佈陣；對戰中匯入會回到佈陣階段。
- 可以連同電腦的佈局一起匯出或匯入。上一次開局用的佈陣會自動記住。
- 擴充版的佈局檔會記下規則組；匯入時規則不同，會提示一鍵切換。改版前的舊佈局檔也讀得到（自動切換到「改版前規則」）。

**複盤與棋譜**
- 對局中或結束後按「複盤這盤」，可以逐手前後移動（也可用 ← → 鍵）、拖滑桿跳到任一手。
- 對局中複盤只看得到自己這方；結束後全部明牌。
- 「匯出棋譜」存下雙方開局佈局、規則組、每一手（含作弊動作）；「匯入棋譜」直接進入複盤。

**電腦**
- **AI 設置**：對手和「幫我下的電腦」各一組，記在瀏覽器裡。
  - **快速套用**：簡單、中等（深度 1）、困難（深度 2）、最難（深度 3），一鍵填好下面各項。改了任一項就顯示「自訂」。
  - **思考深度** 1～5：越深越強，也越花時間。
    - 1 即時：只看這一步。
    - 2 看回應：再看對方最好的回應。
    - 3 推演：猜幾種「對方暗棋可能是這樣」，各推三手再平均。
    - 4 深推演、5 長考：猜更多種，最好的幾手再多推幾手。
    - 選單上會依這台電腦的實測速度顯示「一手約幾秒」，下完顯示實際花了多久。
  - **個性**：均衡、猛攻、穩守、衝鋒、護旗、試探、賭徒。
  - **長考上限**：5～60 秒或不限（預設 15 秒）。想到上限就下目前最好的一步，並標「時間到」。
  - **細項**：隨機性、攻擊性、避險、護旗的滑桿，以及「加強判斷」開關。
  - **軍旗**：正常／不佔軍旗（放水）／清空可動棋。後兩種都「避免輸優先」：自己快輸時才奪旗。放水預設也不吃你最後一顆能動的棋（不靠「無棋可動」贏），可以關掉。AI 不偷看，只依推理避開「可能是軍旗」的棋。
  - 電腦思考時畫面照常能用，狀態列顯示經過秒數，按「立刻下」就用目前最好的一步。
  - 同一局面、同一組設定，一定下出同一步。
- **標示 AI 建議**（開關）：輪到你時，盤面自動標出「幫我下的電腦」建議的下一步。
- **電腦代走一步**：直接替你走（可以悔棋）。
- **走棋提醒**（「設置」卡片，預設開）：AI 覺得你這步明顯不好（會被吃、軍旗被威脅、很可能撞輸或撞雷）時提醒你，並標出它會走的一步。可選「走之前」（先不走，讓你選照走或取消；同一步再點一次也算照走）或「走之後」。提醒用的 AI 可以跟「幫我下的電腦」相同，或另外設定一組。

**設置**
- 和局條件：「連續 N 手沒有對撞判和」可以關掉或改手數（30～150）。佈陣時改；開戰後鎖定，但可以從作弊介面改（記進棋譜）。
- **觀戰**：兩個電腦對打，雙方各用自己的 AI 設置。速度是「每手至少停多久」，電腦想得更久就等它想完。可以隨時暫停接手。
- 電腦不偷看你的棋：只用開局位置、你的移動方式、對撞的勝負來推理。

**作弊介面**（每一項各自開關）
- 無限回合：電腦不走，一直輪到你
- 上帝視角：看見敵方棋面；底下可再勾「也餵給己方電腦」，建議、代走、觀戰時的我方電腦就用真實棋種（對手電腦永遠不偷看）
- 添加棋子（點空格）、刪除棋子（點棋子），兩者可同時開
- 拖曳搬動：任何棋拖到任何格，拖到另一顆棋上就互換
- 交換兩邊棋盤：雙方棋子對調，改由你操控原本電腦的部隊
- 無視佈局條件：可以載入、擺出違規的佈局（軍旗不在大本營、地雷在前線、棋數不對都行）
- 悔棋
- 另外：匯入敵方佈局、讓電腦換一個隨機佈局

**地圖**（只有擴充版）
- 對局頁的「地圖」卡片可以換地圖：內建 5 張（標準、兩國換軌、偏遠平原、沼澤森林、山地），加上你存在瀏覽器裡的。卡片裡有這張地圖的地形圖例。
- 地圖可以匯入、匯出（`.json`）。佈局檔會記下用的地圖；棋譜則把整張地圖存進去，換台電腦也能複盤。
- **地圖編輯器**：格子筆刷、公路剪刀、鐵路筆（標準軌／寬軌／窄軌）、過河口、區域筆刷（偏遠平原、鄉村、沼澤、森林、山地）、鏡像、復原重做。右側即時檢查能不能玩，能玩才可以按「試玩」。
- 地形規則與現實理由見 `docs/rules-expanded-0.md`。印出來的棋盤用圖示＋花紋分辨地形，黑白列印也看得出來。

**音效與音樂**
- 頂端「音量」可以分別調音效、音樂；「聲音」「音樂」是總開關。
- 背景音樂分佈陣、對戰、結束三段；主題依版本或地圖而不同。
- 音效只依你在實體棋盤上也會知道的事發聲（撞到地雷和輸給大棋是同一個聲音）。觀戰「快」時每秒最多 3 個音效。複盤往後一步可以選擇播放事件音效。

**規則開關**（只有擴充版）：每條擴充規則都能單獨關掉，佈陣階段可以改。「改版前規則」一鍵回到舊兵力、新規則全關。

## 佈局檔格式

```json
{
  "format": "luzhanqi-layout",
  "variant": "expanded0",
  "name": "我的佈局",
  "rules": { "newArmy": true, "tankMine": true, "...": true },
  "grid": [
    ["連長","排長","營長","師長","團長","排長","連長"],
    ["偵察","","旅長","坦克","團長","","傘兵"],
    ...
  ]
}
```

- `grid` 的第一列是**前線**（靠中間），最後一列是大本營那一排。每列由左到右。`""` 是空格。
- `variant`：`classic`、`expanded0`、`expanded1`（改版前的 `expanded` 視為擴充版-0）。
- `rules`：擴充版的規則組；沒有這欄時視為改版前規則。
- 選填 `enemyGrid`（電腦的佈局）、`illegal: true`（違規佈局）。
- 棋名可用繁體或簡體。也能讀最舊的 `pieces: [[欄, 列, 名稱], ...]` 格式。
